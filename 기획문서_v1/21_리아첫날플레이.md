# 21. 리아 첫날 — Ren’Py 플레이

실행: 상위 RenPy_게임시작.bat. HTML 관련세폴더와 HTML진입파일은 삭제했다.

진행: 첫출근 → 인사3선택 → 협업/집중 → 문자로점심답장 → 대화/휴식 → 취미선택 → 퇴근전화 → 카페/귀가 → 첫날결과. 전체126대사블록·6대사선택메뉴이며 휴대폰 답장과 전화 선택은 별도화면이다.

협업/점심대화/카페의 결과는 리아호감16·신뢰15·프로젝트3·스트레스11·감각43. 집중/점심휴식/귀가의 결과는 호감11·신뢰10·프로젝트4·스트레스0. 첫날기본호감10에서 문자답장+1은1회만 받는다. 카페는 공식교제데이트가 아니라 취향활동이다.

카페루트에는2일12:30라운지 원자료 검토 약속이 남는다. 2일 이후 플레이는 아직없다. 단계사진은첫날조건을충족하지않으므로 안오는것이정상이다. 기존카페CG는위치공유용으로문자에등장한다.

현재화면은RIA초상시트만움직이며 다른인물스탠딩연출은준비중이다. 배경은사용자원본과신규필요장소를game/images/bg에서불러온다. 저장/불러오기/대화기록/자동진행은Ren’Py화면이다.

위 시제품 구현·검수·한계 기록은 그대로 보존한다. 리아의 확정 외형은 03의 `ria` MASTER이며, 표정 시트·카페 CG는 그 MASTER를 대체하지 않는다. 시제품에서 활용했어도 최종 원화 미승인이다. 특히 시트의 얼굴·몸·입 정렬 차이는 승인으로 해소된 문제가 아니며 추후 검수·수정 대상이다. 기본 나이·직무·성격·말투·전용 표정과 루트는 05를 따른다. 현재 실제 자산 상태는 27에 기록한다.
