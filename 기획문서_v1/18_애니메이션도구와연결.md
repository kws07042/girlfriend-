# 18. 애니메이션 작업 도구와 연결 — 무료 우선

확인일: 2026-10-01. 사용자 최신 기준: **애니메이션은 무료 방식을 우선한다.** 유료 도구 구매·구독·크레딧 소비는 현재 제작 계획에 포함하지 않는다.

## 1. 첫 번째 선택: 기존 그림과 로컬 코드

이미 준비된 그림을 게임 코드에서 교체·이동해 눈 깜빡임, 입 모양 전환, 작은 호흡, 고개 기울임, 등장·퇴장을 만든다. 추가 애니메이션 서비스 연결이나 사용료가 필요하지 않다. 새 그림을 생성하는 서비스 비용과 원화 작업 비용은 이 설명과 별개다.

현재 미리보기가 이 방식이다. 다음 단계는 인물1명의 눈·입·머리·머리카락을 분리하고, 움직임 범위를 작은 각도로 제한해 코드를 작성하는 것이다. 보이지 않던 목·얼굴·귀 부분은 원화를 보완해야 한다.

## 2. 무료 제작 도구

| 우선순위 | 도구 | 활용 | 비용·작업 조건 |
|---|---|---|---|
| 1 | 기존 그림 + 로컬 코드 | 게임 내 반복 움직임·표정 | 별도 애니메이션 서비스 이용료 없음 |
| 2 | Krita 공식 무료 배포판 | 레이어 원화, 눈·입 프레임, 프레임 애니메이션 | 무료·오픈소스. 원화와 편집 작업은 필요 |
| 3 | Blender | 추후 복잡한 제작 흐름 검토 | 무료 소프트웨어. 현재 PC 설치·자동화 경로 미확인 |
| 조건부 | Live2D Cubism FREE | 2D 모델과 기본 애니메이션 | 무료판 제한과 상업 사용 조건, SDK 배포 조건 확인 필요 |

Krita의 무료 제공은 [공식 홈페이지](https://krita.org/en/), 프레임별 애니메이션 기능은 [공식 설명서](https://docs.krita.org/en/user_manual/animation.html)에서 확인했다. Blender 무료 소프트웨어 기준은 [공식 라이선스 설명](https://www.blender.org/about/license/)을 참고한다.

이 도구들은 PC에 설치하는 편집 프로그램이다. 설치만으로 이 세션에 직접 조작 플러그인이 연결되는 것은 아니다. 현재 네이티브 앱 제어는 비활성화되어 있어 편집기를 직접 클릭하는 작업을 보장하지 않는다. 나는 동작 코드, 레이어 설계, 프레임 구성, 내보낸 자산의 게임 연동을 진행할 수 있다.

## 3. Live2D 무료판의 정확한 위치

Cubism FREE는 체험판과 다른 지속적인 무료판이다. 공식 비교표 기준 텍스처1장·최대2048px, ArtMesh100개, 파라미터30개, 영상·이미지 시퀀스 출력 최대1280×720 등 제한이 있다. 제한을 초과하면 저장할 수 없다.

무료판의 상업 사용은 일반 사용자와 연 매출1000만 엔 미만 소규모 사업자에 허용된다. 게임에 SDK를 넣어 배포할 때의 조건은 편집기 무료 여부와 별도로 확인한다. 사용자의 매출·배포 조건을 확인하지 않은 상태에서 무조건 무료 상업 배포라고 판단하지 않는다. [공식 무료·유료 비교](https://www.live2d.com/en/cubism/comparison/).

게임 해상도1920×1080 계획과 무료판 영상 출력1280×720을 혼동하지 않는다. 렌더링 방식과 출력 방식을 먼저 결정한다.

## 4. 생성 영상 서비스와 유료 도구

Higgsfield는 현재 설치·활성화된 도구가 있지만 무료 생성이 보장되는 것은 아니다. Runway는 이전 검색에서 미설치로 확인됐고 추가 연결이 필요하다. 두 도구는 짧은 CG 영상의 후순위 선택지로만 남긴다. 무료 우선 작업을 위해 추가 연결할 필요는 없다.

Spine과 Live2D PRO는 현재 권장 설치·구매 목록에서 제외한다. 무료 작업 범위로 부족할 때만 별도 비용 검토를 한다. 현재 유료 생성이나 설치를 실행하지 않았다.

## 5. 프로젝트 진행 기준

1. 기존 이미지로 깜빡임·호흡·표정 교체를 먼저 완성한다.
2. 원화가 필요한 부분은 Krita를 사용해 레이어·프레임을 준비하는 흐름을 설계한다.
3. 단순 레이어 움직임은 코드로 구현한다.
4. 연속적인 고개 각도 등 정교한 움직임이 꼭 필요할 때 Cubism FREE 제한 내 제작을 검토한다.
5. 무료 방식으로 부족한 항목이 확인되기 전에는 유료 연결을 요구하지 않는다.

## 2026-10-01 후속 메모 — 무료 우선 범위 유지

현재 실행 엔진은 사용자 확정 Ren’Py이고 초안 움직임은 20을 따른다. 도구별 기존 소개·링크는 이력이며 이번 MD 동기화에서 가격·최신 기능·외부 연결을 다시 검증하지 않았다. 무료 우선 기준을 유지하고 새 도구 설치·계정 연결·유료 서비스 사용은 수행하지 않았다. 정지 그림으로 완성 가능한 기본 게임을 유지하며, 파츠 분리·Live2D·보이스를 의무 제작 항목으로 추가하지 않는다.
