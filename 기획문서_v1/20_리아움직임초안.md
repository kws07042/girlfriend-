# 20. 리아 Ren’Py 움직임 초안

이전 HTML 움직임 미리보기는 사용자 요청으로 삭제했다. 원본 PNG는 예시자산_v1에 보존했고 RenPy_게임/game/images/cg로 복사했다.

현재 assets.rpy는 기존3패널을 Crop으로 나누고 open/blink/quiet 표정을 정의한다. 눈 깜빡임은3.6초/2.8초 간격에0.12초 닫힌패널, 전체 초상은2.4초 주기로3px이동·0.25도기울임을 사용한다. 설정의 움직임 줄이기를 켜면 다음장면부터 정지초상으로 표시한다.

완성된 독립 레이어 리깅이 아니다. 패널별 머리/몸윤곽이 달라 미세한 도약이 있을수 있다. 향후 눈·입·머리·머리카락 레이어를 분리해 일부만 움직이는 방식으로 교체한다. 무료Ren’PyATL부터 진행하고 큰고개회전은 원화추가 후검토한다.

## 2026-10-01 후속 메모 — MASTER와 예시 자산 승인

위 시제품 구현·검수·한계 기록은 그대로 보존한다. 리아의 확정 외형은 03의 `ria` MASTER이며, 표정 시트·카페 CG는 그 MASTER를 대체하지 않는다. 시제품에서 활용했어도 최종 원화 미승인이다. 특히 시트의 얼굴·몸·입 정렬 차이는 승인으로 해소된 문제가 아니며 추후 검수·수정 대상이다. 기본 나이·직무·성격·말투·전용 표정과 루트는 05를 따른다. 현재 실제 자산 상태는 27에 기록한다.

## 2026-10-01 후속 메모 — UI v2

사용자가 새 UI 시안을 요청해 28의 현재 UI를 적용했다. 위 초기 초상/움직임 기록은 당시 구현 이력이다. 지금 이야기 화면은 네 승인 MASTER의 화자별 정지 스탠딩이며 리아 표정 시트 전체 교체를 재생하지 않는다. 기존 예시 승인 한계는 유지한다. 캐릭터 독립 레이어 움직임은 별도 이미지 작업이고 UI 진입 효과와 구분한다.
