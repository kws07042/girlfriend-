# 13. Ren’Py 구현 명세

확정 엔진은 Ren’Py. 브라우저 구현은 삭제했다. 실행 프로젝트 `RenPy_게임`, 무료 SDK `도구/renpy-8.5.3-sdk`, 실행 진입점 `RenPy_게임시작.bat`.

## 1. 실제 디렉터리

```text
RenPy_게임/
  game/options.rpy        제목·해상도·저장 경로
  game/state.rpy          상태·메시지·사진 판정
  game/assets.rpy         배경 레지스트리·리아 ATL
  game/screens.rpy        대사·휴대폰·저장·설정
  game/story_day01.rpy    실제 첫날 22노드와 통화
  game/images/bg/        실행용 배경
  game/images/characters/ 캐릭터 마스터
  game/images/cg/        기존 리아 표정·카페 CG
  game/images/phone/     단계 사진 파일 자리
  game/fonts/           SDK 제공 한국어 글꼴
```

상위 `원본자료/배경/사용자원본`는 사용자 원본 폴더. 같은 이름으로 실행용 폴더에 복사하며 `배경동기화.ps1`로 갱신한다. 배경 이미지에 문자/UI를 합성하지 않는다. `assets.rpy`의 레지스트리에 키와 파일을 추가해 장면에서 사용한다.

## 2. 저장 데이터

`default stats`, `people`, `flags`, `phone_messages`, `phone_calls`, `phone_events`, `phone_replied`, `reply_reward_days`, `photo_received`, `photo_saved`, `photo_hidden`, `promises`를 사용한다. 모두 일반 세이브와 롤백 대상이다. 움직임 설정만 `persistent.reduce_motion`이다. 일자·시간·장소·챕터도 저장된다.

각 인물의 현재 코드 필드는 affection/trust/episode_stage/relationship/core_resolved/photo_cap/private_photo_ok/breach. 본편에서는 consent/scene_permissions/publicity_scope/contact_hours를 추가하고 기본값 마이그레이션을 작성한다. 미구현 필드를 지금 사용 중이라고 표시하지 않는다.

## 3. 사건과 화면의 역할

대사·시간·보상·분기는 `label`에서 처리한다. 휴대폰 화면은 상태를 표시하고 답장·허용 범위·즐겨찾기 변경 액션만 실행한다. 자동 사진 해금은 사건 종료에 호출한다. 화면 평가/예측/그리기 중 데이터를 변경하지 않는다.

`send_message(id)`는 phone_events로 중복 전송 방지, `reply_message(id,option)`은 phone_replied로 중복 답장 방지 및 일자별 호감 상한1을 적용한다. `photo_allowed(person,rule)`은 관계·사건·동의 검증, `queue_photo_rewards()`는 파일 존재와 쿨다운을 추가 확인한다.

## 4. 실제 구현 범위

첫날 출근/세 인물 소개/리아와 업무 선택/점심 문자 답장/점심대화 또는 휴식/퇴근 전화/카페 또는 귀가/결과 화면. 카페 분기는 다음 날 라운지 약속을 남긴다. 업무와 휴식 수치는09문서와 같다. 사진 확대 및 내부 저장표시는 구현됐지만 캐릭터 단계사진은 아직 제작하지 않았다.

UI v2에서는 네 승인 MASTER의 실행용 동일 복사본을 화자에 맞춰 정지 스탠딩으로 표시한다. ui_speaker는 표시용 상태이며 관계/수치 판정에 사용하지 않는다. 눈·입 독립 레이어 움직임은 별도 자산 작업이다.

2일 이후의90슬롯 일정 실행기, 개인16사건,6협업,5그룹사건,15엔딩,선택 전 자동저장,회상도감은 미구현. 첫날 결과 화면에서 이를 명시한다.

## 5. 배경/애니메이션 로딩

`office_bg(key)`는 레지스트리 PNG를1920×1080 cover로 표시한다. 없는 파일은 단색 임시 배경을 사용해 게임 중단을 막는다. 공급한14장과 신규 배경3장을 연결했다. 배경 키는 office/evening/lounge/terrace/cafe/home/meeting/meeting_night/studio/development/marketing/elevator/hotel/restaurant/rooftop/rain/bar.

기존 리아3패널 Crop/ATL 정의와 시트는 예시 이력으로 남긴다. 현재 UI v2의 이야기 화면은 원본 기반 정지 스탠딩이며 3패널 전체 교체를 재생하지 않는다. UI 진입 효과는 ui_design.rpy의 ATL이며 움직임 줄이기에서 즉시 표시한다. 상세 변경과 미리보기는 28을 따른다.

## 6. 폰 액션 계약

`screen phone(mode=None)`는 자유 확인일 때 Hide로 닫고 점심/전화의 강제 확인일 때 Return으로 스토리에 결과를 반환한다. 점심은 실제 답장을 보낸 후에만 진행. 전화는 받기/부재중 선택 이후 통화 대사 또는 귀가 분기로 이동한다. 자유 화면에서 통화를 새로 시작하지 않는다.

휴대폰 하위사진 screen은 더 높은zorder의modal로 열고 닫힌 뒤 원래 문자/앨범으로 돌아간다. 전체 게임 저장 화면은 Ren’Py ShowMenu, 저장은 FileAction/FilePage, 기록은 _history_list를 사용한다.

## 7. 버전과 검증

SDK8.5.3을 공식 다운로드로 받아 프로젝트 도구 폴더에 보관했다. 명령행 lint/compile과 엔진 내 testcase로 검사한다. 검증 결과는26문서에 기록한다. 실제 파일에서 확인한 버전이며 시스템 전체 설치나 유료 플러그인은 필요 없다.
