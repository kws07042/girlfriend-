# 16. 캐릭터 애니메이션 — 무엇을 만들 수 있는가

제작 기준: 무료 우선. 기존 그림·로컬 코드·무료 원화 도구로 진행하며 유료 생성 영상은 기본 범위에 넣지 않는다. 상세 기준은 [18_애니메이션도구와연결.md](18_애니메이션도구와연결.md)를 따른다.

## 1. 가능한 범위

눈 깜빡임, 입 모양 교체, 표정 전환, 작은 호흡, 가벼운 고개 기울임, 등장·퇴장, 시선 이동, 폰 진동을 구현할 수 있다. 손을 크게 움직이거나 머리를 돌아 옆얼굴을 보여 주는 동작은 추가 그림·레이어·리깅 작업이 필요하다. 한 장만으로 보이지 않는 얼굴 뒷면까지 정확히 복원한다고 보장할 수 없다.

## 2. 방식 비교

| 방식 | 필요한 것 | 가능한 동작 | 한계 |
|---|---|---|---|
| 전체 이미지 이동 | 정지 그림1장 | 호흡 느낌·등장·작은 기울임 | 몸·배경까지 함께 움직임 |
| 프레임 교체 | 눈·입·포즈별 그림 | 깜빡임·말하기·2포즈 고개 | 그림 간 위치·얼굴 차이 |
| 분리 레이어 2D | 얼굴·눈·입·머리·몸·머리카락 | 자연스러운 작은 고개·머리카락 | 가려진 부분 보완 원화 필요 |
| 전용 2D 리깅 | 레이어 원화와 변형 설정 | 연속 각도·표정·물리 | 세팅·검수 비용 증가 |
| 짧은 생성 영상 | 장면 이미지·영상 제작 과정 | 특정 CG의 짧은 장면 | 얼굴 변화·루프·실시간 반응 문제 |

MVP는 프레임 교체와 미세 이동으로 시작한다. 한 캐릭터를 완성해 품질을 확인한 뒤 레이어 방식으로 확장한다. 도구·제품별 최신 기능 비교를 확정한 문서는 아니다.

## 3. 이번 예시

`보관자료/01_예전시안/예시자산_v1/ria_expression_sheet_v001.png`: 왼쪽 기본, 중앙 눈 감기, 오른쪽 고개 기울임. 생성된 이미지1장 안의 3영역을 CSS에서 잘라 보여 주는 시연이다. 원본 파일을 물리적으로 잘라 수정하지 않았다.

`보관자료/01_예전시안/예시자산_v1/ria_cafe_cg_v001.png`: 카페 CG·폰 사진의 시각 예시.

`미리보기_v1/index.html`: 브라우저에서 여는 로컬 단면. 깜빡임·포즈 교체·미세 호흡과 폰 대화·사진·통화 예시. 프레임 교체는 연속적인 실제 고개 회전과 다르며 얼굴·입·몸 정렬에도 생성 차이가 있다. 이 시트는 제작용 최종 레이어가 아닌 컨셉 검토 자산이다.

## 4. 기본 타이밍

- 깜빡임: 약3~5초 간격, 닫힘100~140ms. 테스트는 일정한 간격, 실제 게임은 고정된 시드의 소폭 변화 가능.
- 입 모양: 대사 출력 중 closed / small / open 3종을 약90~160ms 간격으로 전환. 음성 없이 정확한 발음 립싱크로 소개하지 않는다.
- 고개: 기본과 기울임을 대사 의미에 맞춰 전환. 완성판은 중간 포즈 추가 또는 분리 레이어 보간.
- 호흡: 약4초 루프, 세로2~4px·스케일0.3~0.6% 이내를 출발값으로 사용.
- 머리카락: 분리된 끝부분만 작은 회전·이동. 포니테일 전체를 고무처럼 늘리지 않기.

목·귀·얼굴의 가려진 면은 원화에서 메워야 고개 움직임 때 구멍이 생기지 않는다. 원본 배경 제거만으로 이 레이어가 자동 완성되지 않는다.

## 6. 캐릭터별 동작 성격

서윤: 고개를 조금 끄덕이고 펜을 내려놓은 뒤 질문. 리아: 짧은 기울임과 활기 있는 눈, 포니테일 끝의 작은 후행 움직임. 유진: 시선 먼저 움직이고 늦게 미소. 지현: 몸은 안정적으로 유지하고 눈·입의 작은 변화 중심.

네 명의 호흡과 표정 전환을 같은 리듬으로 복제하지 않는다. 화면 전체 흔들림보다 시선과 표정의 이유가 우선이다.

## 7. 검수

얼굴·의상·소품의 위치가 프레임마다 튀는지 확인한다. 눈 감김이 웃는 눈으로 변해 감정이 달라지지 않는지 확인한다. 머리카락과 귀걸이가 얼굴을 뚫지 않아야 한다. '움직임 줄이기'를 켜면 정지 표정으로 대사와 선택은 그대로 진행한다.

## 8. 생성 기록

두 이미지 모두 기본 내장 이미지 생성 도구를 사용했고 원본2번을 참조했다. 원본은 수정하지 않았다. 정확한 생성 프롬프트는 [17_예시이미지생성기록.md](17_예시이미지생성기록.md)에 기록한다. 출력 픽셀 크기는 파일 검수 결과를 같은 기록에 추가한다.

## 2026-10-01 후속 메모 — 현재 실행과 승인 범위

이 문서의 HTML/CSS 시연 설명은 초기 예시 이력이다. 해당 웹 폴더는 사용자 요청으로 삭제했으며 현재 실행은 20·21·26의 Ren’Py다. 리아 예시 시트 활용은 최종 원화 승인을 뜻하지 않는다. 03의 승인 MASTER를 기본형으로 유지하고, 표정·눈 감기·기울임은 같은 인물의 연출 변형으로 판정한다. 이 MD 정리로 독립 파츠·Live2D·입 움직임·보이스 구현을 추가하지 않는다. 제작 수량은 14, 무료 우선 제작 방식은 18이며 정지 그림만으로도 기본 게임을 완성할 수 있다.
