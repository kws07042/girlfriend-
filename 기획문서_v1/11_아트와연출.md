# 11. 아트와 연출

## 1. MASTER 보존과 변형의 적용 범위

외형의 기준은 [03의 확정 MASTER 대응표](03_캐릭터비교와관계.md#1-확정-master-대응표)다. 새 표정·의상·포즈·CG·폰 사진은 해당 인물의 승인 MASTER를 참조한다. 얼굴 정체성·기본 신체 비율·기본 헤어·그림체를 유지하고, 성격과 말투는 04~07을 따른다. 정확한 나이·신장·직무를 이미지에서 추정하지 않는다.

| 구분 | 적용 원칙 |
|---|---|
| 인물 정체성 | 얼굴 형태·눈 배치·기본 비율·머리와 눈의 기준색·선화·채색 유지 |
| 기본 오피스 의상 | MASTER의 구조·색을 해당 기본 세트에서 유지 |
| 기존 캐주얼·행사 의상 | 아래 4절 및 개인 문서에 있는 같은 인물의 별도 변형 |
| 표정·자세·카메라 | 눈 감기·시선·감정·원근 변화 허용. 다른 얼굴이나 체형을 허용한다는 뜻은 아님 |
| 장면 소품 | 12의 태블릿·커피·폴더 유무, 재킷 착용 여부, 손 위치 변경 허용 |
| 보존 앵커 | 유진의 금색 장신구·지현의 시계는 계속 유지. 위 장면 소품과 혼동하지 않음 |

서윤의 기본 헤어는 낮은 번이다. 04의 후반 사적 의상에서만 머리 푼 모습을 선택적으로 허용하며, 별도 파생 변형으로 관리한다. 기본 MASTER 교체나 전 장면 자유 변경으로 확대하지 않는다.

MASTER를 덮어쓰지 않는다. 얼굴이 달라진 파생 결과는 결과물 수정 또는 보류 대상이다. 실제 참조 이미지 없이 문구·시드만 쓴 작업을 MASTER 참조 생성으로 기록하지 않는다. 제작 절차·규격·명명·승인은 12, 현재 파일 기술 정보와 예시 승인 상태는 03·27에서 관리한다.

## 2. 레이어 구조

캐릭터당 body / face / front_hair / back_hair / prop을 가능한 범위에서 분리한다. 초기 MVP는 레이어 대신 동일 포즈의 완성 PNG 표정 변형으로 시작할 수 있다. 별도 얼굴 레이어를 쓰려면 머리·목·어깨와 얼굴 좌표가 정확히 일치해야 한다.

위 레이어 분리는 가능한 경우의 선택 절차이며 의무 리깅 작업이 아니다. 제작량은 14를 따르고 정지 그림으로도 기본 게임을 완성할 수 있다. 무료 우선 기준은 18을 유지한다.

레이어 순서: 배경 → 뒤쪽 소품 → 뒷머리 → 몸 → 얼굴 → 앞머리 → 앞쪽 소품 → 효과 → 대사창 → 핸드폰 버튼·HUD. 핸드폰을 열면 세계 장면 위에 어두운 배경막과 기기 화면이 올라온다.

## 3. 표정과 자세

| 범용 표정 8종 | 사용 |
|---|---|
| neutral | 일반 대화 |
| smile | 편안한 호감 |
| serious | 업무·경계 |
| worried | 고민 |
| embarrassed | 마음을 드러낸 뒤의 어색함 |
| upset | 약속 위반·오해 |
| surprised | 뜻밖의 정보 |
| relaxed | 사적 편안함 |

캐릭터별 전용 표정 2종은 개인 문서를 따른다. 과한 홍조·울음·입 모양을 모든 캐릭터에 같은 형태로 적용하지 않는다. 기본 전신은 1포즈, 보조 포즈는 1포즈로 제한해 표정 합성 비용을 관리한다.

## 4. 의상

완성판은 캐릭터당 기본 오피스·퇴근 후 캐주얼·공식 행사 3세트. CG 전용 의상은 세트의 일부로 재사용한다.

| 인물 | 캐주얼 방향 | 행사 방향 |
|---|---|---|
| 서윤 | 밝은 니트와 편한 팬츠, 낮은 번 기본; 후반 사적 장면만 04의 풀어낸 머리 예외 | 푸른 계열 셔츠와 정돈된 재킷 |
| 리아 | 네이비·청회색을 유지한 편한 상의와 스커트 | 움직임 좋은 단정한 드레스 |
| 유진 | 짙은 색 블라우스와 긴 스커트 | 와인색·금색의 절제된 원피스 |
| 지현 | 단색 니트와 슬랙스 | 기존 흑백 정장의 공식 변형 |

성인 분위기는 성숙한 얼굴, 자연스러운 자세, 의상 질감, 조명과 관계의 맥락으로 만든다. 의상 변화로 다른 사람처럼 보이거나 미성년 외형으로 어려지지 않게 한다.

## 5. CG 15종 기준

공통 3: 첫 TF 회의, 확대 요청 회의, 런칭 행사.

개인 8: 캐릭터당 취향 공유 1 + 관계 확인 1.

복수 관계 2: 같은 테이블, 함께 고른 다음 일정.

엔딩 2: 퇴근길 개인 엔딩 공용 구도, 다 함께 나서는 출입구.

총 15종. 표정·조명 변형은 별도 고유 CG 수에 추가하지 않는다. 개인 공용 엔딩 CG의 인물 레이어는 4종이 필요하다. 암전 뒤의 직접적인 성행위 그림은 이 범위에 없다.

## 6. 공간과 색

10개 기본 배경과 4개 시간대 변형: office 야간, meeting 야간, terrace 저녁, cafe 저녁. 총 14 배경 파일을 초기 목표로 한다. 낮·밤 변형은 조명 구조를 유지하며 단순 파란 필터만으로 처리하지 않는다.

서윤: 푸른색·따뜻한 회색. 리아: 네이비·청회색·금빛. 유진: 와인색·금색·흑청색. 지현: 검정·흰색·차분한 은색. UI 전체는 밝은 회색과 남색을 사용하고 인물 색은 프로필과 알림 강조에만 적용한다.

## 7. 카메라

일상은 눈높이와 허리 위 구도, 개인 감정은 얼굴·손·소품 클로즈업, 집단 사건은 시선 방향이 읽히는 넓은 구도. 시선을 신체 일부에 반복 집중하지 않는다. 대사창이 손과 핵심 소품을 가리지 않도록 안전영역을 확보한다.

스탠딩은 발바닥 좌표를 공통 기준으로 하되 신장 설정 차이를 표시한다. 화면 흔들림은 업무 사고에 짧게 사용하고 접근성 옵션에서 끌 수 있게 한다.

## 8. UI

메인 HUD: 날짜·슬롯·프로젝트·컨디션·관계·저장·핸드폰. 현재 UI v2의 핸드폰 버튼은 오른쪽 위 HUD 영역에 고정한다. 상세 시안과 구현은 28을 따른다. 알림 점은 게임 속 미확인 연락만 나타내며 OS 알림은 발생시키지 않는다.

관계 화면에는 '필요한 사건'과 '관계 의향'을 표시한다. 호감 게이지가 교제 동의를 대체하지 않도록 별도 상태 문구를 둔다. 키보드·마우스 모두 지원하는 설계다.

## 9. 소리

배경 음악 8곡: 오피스, 일상, 협업, 갈등, 데이트, 관계 대화, 행사, 엔딩. 효과음 20종 이내: 컵·펜·키보드·메시지·전화·진동·문 등. 전화 소리는 메시지보다 낮고 짧은 진동으로 예고한다. 알림 효과는 연속 메시지마다 울리지 않고 묶어서 한 번만 재생한다.

풀 보이스는 완성판 선택 사항이다. MVP는 텍스트와 알림 소리만으로 통화를 표현한다. 통화가 실제 음성 녹음을 요구하는 기능은 아니다.

## 10. 접근성과 표시

텍스트 크기 3단계, 대사 속도, 대비, 화면 효과, 전화·메시지 효과음 음량을 각각 조정한다. 메시지 정보는 색만으로 구분하지 않고 이름·시간·읽음 문구로 표시한다. 폰 화면은 작은 원본 픽셀을 확대하는 방식이 아니라 UI 요소를 실제 해상도에 맞춰 렌더링한다.
