# 오피스 미연시 기획 문서

확정 엔진은 **Ren’Py**다. 사용자 지시에 따라 전환한 현재 실행 프로젝트는 상위 `RenPy_게임`, 시작 파일은 `RenPy_게임시작.bat`이다. 지금 플레이 가능한 범위는 리아 첫날이며 6주 본편은 제작 예정이다. HTML 관련 폴더는 삭제했다.

## 분야별 기준

**수치 09, 데이터 계약 13, 인물 말투 개인 문서, 제작 수량 14 우선.** 문서 번호나 수정 날짜로 전체 문서에 단일 서열을 매기지 않는다. 확정 MASTER는 외형 기준이며 개인 설정·직무·정확한 설정 나이·신장·수치를 덮어쓰지 않는다.

| 분야 | 기준 |
|---|---|
| 작품 범위·공통 전제 | 이 README·01 |
| 세계관·조직·직무 | 02 |
| 비교·상호 관계 | 03 |
| 개인 설정·성격·말투·성장 | 04~07 |
| 승인 외형 | 03에서 연결한 인물별 확정 MASTER |
| 공통 아트·연출 / 제작·출력·명명·승인 | 11 / 12 |
| 스토리·루트 / 사건·대사 적용 | 08 / 10 |
| 게임 수치·판정 / 데이터·저장·연결 | 09 / 13 |
| 제작 수량·단계 | 14 |
| 핸드폰 기능 | 15, 말투는 04~07 |
| 움직임 / 무료 우선 제작 방식 | 16 / 18 |
| 생성·검수·시제품 이력 | 17·19~21 |
| 친밀 연출·사건 배치·배경·사진 세부 | 22~25, 분야별 기준을 확대하거나 덮어쓰지 않음 |

사진 단계 조건은 25, 현재 코드 계약은 13, 실제 검수 결과는 26에 기록한다. 캐릭터 단계 사진은 지금 생성하지 않는다. 중간 단계는 옷을 입은 가슴골 셀카이며 파일이 실제 존재하고 허용 조건을 충족할 때만 전송한다.
