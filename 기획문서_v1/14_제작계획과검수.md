# 14. 제작 계획과 검수

## 1. 단계

| 단계 | 목표 | 완료 기준 |
|---|---|---|
| A 기획 | 설정과 수치 확정 | 개인·복수 관계 도달 일정 검증 |
| B 세로 단면 | 하루와 한 인물 사건 | 대화→행동→메시지→전화→저장 전체 흐름 |
| C MVP | 1주·4인 소개·폰 | 모든 기본 화면과 프롤로그 플레이 |
| D 알파 | 6주·모든 루트 | 임시 자산으로 15엔딩 도달 |
| E 베타 | 아트·소리·편의 | 보상 중복·대본 단절·표시 문제 제거 |
| F 출시 준비 | 권리·등급·배포 | 선택 판매처 기준 확인과 패키지 검수 |

기간은 작업 인원·자산 제작 방식·실제 분량이 확정되지 않아 견적하지 않는다. 엔진은 사용자 지시로 Ren’Py 확정이다. 현재 Ren’Py 리아 첫날은 세로 단면이며 MVP 전체 게임은 아니다. 기존 HTML 단면은 사용자 요청으로 삭제했으며 이력은 19에서 구분한다.

## 2. 완성판 자산 목표

| 자산 | 수량 | 산식 |
|---|---|---|
| 기본 standing | 4 | 인물당 1 |
| 범용 표정 | 32 | 4인×8종 |
| 전용 표정 | 8 | 4인×2종 |
| 보조 포즈 | 4 | 4인×1종 |
| 의상 세트 | 12 | 4인×3세트, 기본 포함 |
| 배경 | 14 | 기본10·시간대4 |
| 고유 CG | 15 | 공통3·개인8·그룹2·엔딩2 |
| 폰 프로필 | 4 | 인물당 1 |
| 폰 사진 | 16 | 인물당4, 일부 CG 재사용 가능 |
| 음악 | 8 | 장면 톤별 |
| 효과음 | 최대20 | UI·소품·환경 |

표정·포즈·의상은 조합 목록이므로 모두 곱한 완성 PNG를 사전 출력하지 않는다. 실제 레이어 구조가 없으면 필요한 조합만 우선 제작한다. 폰 사진은 신규 그림 개수와 파일 개수를 구분한다.

## 3. 대본 목표

6공통 체크포인트 + 16개인 핵심 사건 + 6조합 협업 + 3그룹 사건(H01/H03/H04) + 15엔딩 =46 주요 장면. 루트 선택, 반복 대사, 회복 대화, 메시지와 데이트는 별도다.

H02는 개인 사건4의 그룹 참여 의향 대화이며 H05는 엔딩이라 46개에 중복 계산하지 않는다. 주요 장면은 평균 700~1200자의 한국어 대사·지문으로 시작하되 실제 플레이 길이 목표에 맞춰 확장한다.

폰 대화는 인물당 8 스레드·총32개, 통화는 인물당2개·총8개, 짧은 일반 메시지는 별도 20개 이내. 모든 메시지가 새 CG를 요구하지 않는다.

## 4. 폰 MVP

메인 핸드폰 버튼, 홈 화면, 캐릭터별 대화방4개, 답장 선택, 미확인 표시, 사진1장, 수신·부재중·통화 기록, 통화 텍스트, 약속1개, 저장 복원. 앱스토어·실제 통신·SNS 피드는 넣지 않는다.

## 5. 애니메이션 MVP

눈 깜빡임2프레임, 고개 기울이기2포즈, 전체 이미지 미세 호흡 이동. 사진 전체의 움직임과 실제 머리·머리카락 레이어 움직임을 구분한다. 기본 게임은 정지 그림으로도 완성할 수 있다.

## 6. 기능 확인 목록

- [ ] 한 사람에게만 집중해 좋은 개인 엔딩 도달.
- [ ] 4인 핵심 사건과 6조합 협업을 15일 안에 배치.
- [ ] 복수 관계의 전원 수락·일부 거절·철회 분기 확인.
- [ ] 평가권 이관 없이 지현 교제·그룹 확정 불가.
- [ ] 프로젝트가 낮아도 열린 연애 결말 존재.
- [ ] 동일 사건·메시지·전화 보상을 중복 지급하지 않음.
- [ ] 친밀 장면 스킵 시 동일 결과.
- [ ] 폰을 닫았다 열면 대화 위치·읽음·답장 복원.
- [ ] 통화 중 저장·불러오기와 부재중 콜백 정상.
- [ ] 약속 변경이 달력·대화·본게임 일정에 동시 반영.
- [ ] 1280×720부터 2560×1440까지 텍스트 잘림 없음.
- [ ] 원본 캐릭터 얼굴·헤어·색 일관성.

## 7. 제작 위험과 대응

분기 폭증: 일부 인원 그룹은 v1 제외. 표정 파일 폭증: 필요한 조합만 출력. 주말 시간 무한 증가: 저녁 예약 슬롯 비용으로 통일. 폰 연락 과다: 같은 시점 알림 묶기, 하루 핵심 연락1개. 생성 프레임 얼굴 흔들림: 예시는 교체형으로 제한하고 정식 제작에서 좌표·레이어 수정.

## 8. 다음 결정 사항

엔진 Ren’Py와 네 MASTER 디자인·그림체는 사용자 확정 사항이다. 실제 대본 분량, 풀 보이스 채택 여부, 판매처, 작업 인원, 선택적 애니메이션의 세부 범위는 별도 결정 사항이다. 풀 보이스·리깅은 필수 작업이 아니며 애니메이션은 18의 무료 우선을 따른다. 이미 확정된 설정을 다시 묻기보다 작은 플레이 단면으로 확인하고 결정한다.
