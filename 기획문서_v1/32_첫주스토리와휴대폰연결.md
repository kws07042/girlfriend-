# 32. 첫 주 스토리와 휴대폰 연결

작성: 2026-10-02. 실제 Ren’Py 구현 범위는 1~5일차다. 6~30일차, 개인 사건 2~4, 15일차 루트 선택 및 엔딩은 여전히 기획 단계다. 08·09·23의 사건 배치와 관계 규칙을 유지한다.

## 1. 첫 주 이야기의 목적

첫날에는 회사와 휴대폰을 배우고, 2~4일차에는 각 인물이 일하는 이유를 발견한다. 5일차에는 서로 다른 성공 기준을 하나의 목표표에 연결한다. 주인공이 네 사람을 대신 해결하거나 직장 내 친절을 교제 승인으로 해석하지 않는다. 친밀감은 기억한 취향, 구체적인 질문, 지킨 약속, 먼저 오는 연락으로 표현한다.

| 일차 | 오전 | 점심 | 저녁과 연락 | 다음 날로 남기는 것 |
|---|---|---|---|---|
| 01 | 출근·업무 선택 | 리아 초대 수락 / 휴식 | 리아 전화·카페 / 귀가 | 취미, 원자료 검토 약속 여부 |
| 02 | SY01 남겨진 체크리스트 | 리아 원자료 검토 / 미리 조정하고 휴식 | 서윤 전화 수락 / 문자로 확인, 귀가 후 서윤 메시지 | 도움의 범위, 원자료 이행 / 3일차로 조정 |
| 03 | RI01 커피 뒤의 숫자 | 네 사람 중 한 명 / 휴식 | 혼자 카페 / 귀가, 리아 메시지 | 관찰과 가설의 구분, 검토 약속 완료 |
| 04 | YJ01 두 개의 시안 | 네 사람 중 한 명 / 휴식 | 유진 전화 수락 / 문자로 확인, 유진 메시지 | 시안의 목적 / 취향, 통화 여부 |
| 05 | C01 목표 합의 | 네 사람 중 한 명 / 휴식 | 리아 카페 / 서윤 차 / 유진 작업실 정리 / 지현 퇴근 인사 / 귀가 | 목표 합의 방식, 첫 주 관계와 완료 일정 |

지현의 JH01은 기존 23의 **6일차** 배치를 유지한다. 첫 주에 지현에게 답장하거나 점심을 먹어도 개인 사건 단계가 자동으로 오르지 않는다. 금요일 저녁 선택은 일반 취향 활동·인사이며, 조건이 필요한 공식 개인 데이트 또는 루트 확정이 아니다.

## 2. 개인 사건과 결과

SY01: 숨은 업무를 모두 대신 처리하기보다 필요한 범위를 묻는다. 테스트 계정 상태 확인이라는 작은 일을 이행하고 담당자·확인 시각을 남긴다.

RI01: 성공 숫자뿐 아니라 실패한 문구를 살펴본다. 관찰과 해석을 구분하고 리아가 직접 기록 방법을 설명한다. 첫날·둘째 날 검토 여부에 따라 도입 문장이 달라진다.

YJ01: A의 분위기와 B의 시작 행동을 비교한다. 고르지 않은 시안을 실패로 폐기하지 않고 쓰일 자리와 수정 이유를 남긴다. 무조건 칭찬하는 대신 어떤 부분이 남았는지 말한다.

C01: 방문 → 첫 행동 → 다음 날 경험을 나누거나, 확정 내용 → 검증 내용으로 나눈다. 기획 50 이상이면 빠진 접점을 검증하는 선택도 열린다. 세 선택 모두 프로젝트 +10을 받는다. 능력 조건은 유일한 성공 경로가 아니다.

| 처리 | 호감 | 신뢰 | 단계 / 기타 |
|---|---:|---:|---|
| SY01·RI01·YJ01 협력적 기본 선택 | +10 | +12 | 해당 인물 단계1 |
| 대안을 제안한 뒤 범위를 다시 확인하는 선택 | +5 | +6 | 해당 인물 단계1 |

| 점심 휴식 | 변화 없음 | 변화 없음 | 스트레스 -15 |
| 새 답장 | +1 | 변화 없음 | 하루 대상별 1회 상한 |
| C01 | 변화 없음 | 변화 없음 | 프로젝트 +10, 1회 |

첫날 리아 점심도 주간 2회 상한에 포함한다. 상한 이후에도 대화·휴식 효과는 유지하고, 점심 선택 문구에 호감 +0을 표시한다. 개인 발견 사건으로 프로젝트를 올리지 않는다. 단계1에서는 `core_resolved`와 SY03·RI03·YJ03·JH03 핵심 플래그를 설정하지 않는다. 누구도 교제 상태로 자동 변경하지 않는다.

## 3. 메시지의 역할과 말투

새 대화는 첫날 전용 리아 코드에서 네 인물 공통 처리로 확장했다. 메시지별 `who`, 발신 시각, 수신 문장, 답장 선택, 후속 응답, 기억 플래그를 가진다.

- 서윤: 필요한 범위를 천천히 설명하고 상대가 기다려 준 일을 기억한다. 밤에는 자신의 목록과 차 이야기를 짧게 남긴다.
- 리아: 짧은 질문과 가벼운 농담을 쓰되 실패한 가설을 설명할 때는 진지하게 말한다. 첫날 취미와 쉬겠다는 답도 기억한다.
- 유진: 존댓말을 유지하고 시안 의도와 남은 감상을 묻는다. 설명하기 위한 잠깐의 침묵을 허용한다.
- 지현: 확인할 항목과 결론을 먼저 적는다. 금요일 연락에서 업무 종료 시점을 명확히 한다.

답장 시 전송 중 → 전송됨 → 읽음이 표시된다. 타이핑과 응답 시점은 서윤 1.8/4.5초, 리아 1.2/3.8초, 유진 2.0/4.8초, 지현 1.4/3.6초다. 연출용 고정 지연이며 호감이나 실제 네트워크 속도를 뜻하지 않는다. 전화·문자 열기 자체는 슬롯을 쓰지 않는다.

스토리 진행에 필요한 오전·점심 답장은 답장 완료와 후속 응답 도착 뒤 ‘계속’이 활성화된다. 저녁 결과 화면에서는 답장 없이도 다음 날로 갈 수 있다. 다음 날에도 일반 안부 문자의 답장 선택과 원문은 유지한다. 점심 초대·시각이 정해진 업무 확인만 기한을 넘기면 답장이 만료되며 원문은 기록에 남는다. 같은 상대에게 여러 미답장이 있으면 최신 또는 현재 스토리의 필수 답장을 우선 보여 주고, 다른 미답장으로 바꾸어 지난 메시지에도 답장할 수 있다. 답장 대상 날짜를 표시하며 늦은 답장의 상대 시점 표현도 조정한다.

메시지 보내기 칸은 기존처럼 시각적 입력 영역이다. 자유 입력이나 생성형 채팅을 구현한 것으로 표시하지 않는다. 실제 전송은 작가가 작성한 선택형 답장으로 한다. 프로필은 사용자가 제공한 4개 사진을 계속 사용한다.

## 4. 약속과 전화

첫날 카페에서 잡은 DAY 02 12:30 약속은 2일차에 실제 원자료 검토로 이어진다. 수락하면 ‘완료’, 미리 쉬겠다고 말하면 기존 약속은 ‘조정’되고 DAY 03 오전 검토가 ‘예정’으로 생긴다. 3일차 자료 장면에서 변경한 약속을 이행한다. 미리 합의한 조정을 불이행이나 신뢰 감점으로 처리하지 않는다.

새 일정은 `id, who, day, slot, time, title, status`를 저장한다. 같은 날짜·슬롯의 예정 약속 중복 등록을 차단한다. 점심과 금요일 저녁은 선택한 한 사람만 등록하고 해당 장면에서 완료한다. 일정 화면에는 완료·조정 기록도 남기며 긴 목록은 화면 안에서 스크롤한다.

첫날의 기존 문자열 약속은 2일차 진입 시 새 일정으로 전환한다. 하루 결과의 ‘다음 약속’에는 예정 상태만 보여 준다. 완료 약속을 계속 다음 만남으로 안내하지 않는다.

2일차 서윤, 4일차 유진 전화는 실제 해당 프로필·이름으로 뜬다. 수락하면 짧은 통화 대사, 거절하면 부재중 기록과 내용 확인 문자로 이어진다. 거절 때문에 업무·호감에 불이익을 주지 않는다. 통화 기록에는 일차·시각·발신자·결과가 남는다. 통화 음성이나 자유 발신 기능은 이번 범위에 포함하지 않는다.

## 5. 구현 파일과 저장

- `game/story_day01.rpy`: 첫날 결과에서 2일차로 연결.
- `game/story_week01.rpy`: 2~5일차 장면, 사건 선택, 전화 후속, 금요일 저녁.
- `game/week_phone.rpy`: 메시지 데이터, 일정·사건 중복 방지, 날짜 시작, 공통 점심, 하루 마무리.
- `game/state.rpy`: 대상별 메시지·답장·하루 보상 처리와 UI 저장 복원.
- `game/phone_live.rpy`: 실시간 전송·타이핑·읽지 않음·스크롤 추적 및 응답 도착 날짜·시각 처리.
- `game/phone_message_policy.rpy`: 기한이 있는 초대와 일반 문자의 구분, 늦은 답장, 미답장 전환과 기존 저장 복구.
- `game/screens.rpy`: 연락 상대 지정, 필수 답장 안내, 전화 발신자, 일정 기록, 네 인물 결과, 다음 날 버튼.
- `game/tests/week_test.rpy`: 연속 플레이, 대체 분기, 일정 조정, 저장·불러오기 검증.

사건 보상은 `completed_events`의 고유 ID로 1회만 적용한다. 화면을 다시 여는 동작이나 전화 수락에는 개인 사건 보상을 붙이지 않는다. 날짜·플래그·관계·메시지·응답 대기·답장 이력·보상 이력·약속·사진 설정은 회차 저장 상태다. 로드 시 UI에서 수정된 값도 선택한 저장 슬롯 기준으로 복원한다. 기존 저장 폴더를 유지했으므로 첫날 저장에서 이어갈 수 있다.

## 6. 아트와 남은 범위

기존 승인 MASTER, 프로필, 배경을 재사용한다. 새 이미지·성인 사진·표정 시트는 생성하지 않았다. 오전은 오피스·마케팅 프로젝트실·디자인 작업실·회의실, 점심은 라운지·테라스, 퇴근은 엘리베이터, 저녁은 카페·집 등 장면에 맞는 기존 배경을 사용한다.

현재 전체 게임은 317개 대사 블록과 13개 선택 메뉴를 포함한다. 추가 표정·눈 깜빡임 리깅, 6일차 이후, 정식 루트 선택, 복수 관계 협의, 상시 자유 일정 편집은 후속 작업이다. 25의 사진 조건은 그대로 남기되 필요한 사진 파일을 이번 작업에서 만들거나 새 수위 단계로 바꾸지 않는다.
