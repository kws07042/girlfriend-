# 28. Ren’Py UI 보강 시안 v2

작업일: 2026-10-01. 사용자 요청에 따라 현재 게임 UI를 보강하고 실제 엔진 화면을 시안으로 제공했다. 브라우저 게임이나 HTML 시제품은 만들지 않았다.

## 시안과 실행

전체 시안은 [UI 미리보기](../UI_시안_v2/README.md)에 모았다. 프로젝트 상위 `RenPy_게임시작.bat`로 현재 게임에서도 같은 화면을 확인할 수 있다. 시안 PNG는 타이틀·대화·선택지·문자·수신 전화·사진 수신 설정·저장·하루 결과 8종이다. 모두 실제 Ren’Py 화면 캡처이며 AI가 그린 가상의 UI 사진이 아니다.

## 디자인 기준

아이보리 #F8F4EE, 차콜 #26343B, 샴페인 #D6B18A. 본게임 대사창은 어두운 반투명 패널에 밝은 글자로 배경 위 가독성을 확보한다. 선택지는 왼쪽, 인물은 오른쪽으로 배치해 얼굴과 주요 소품이 가려지지 않는다. HUD는 날짜/장소/챕터를 작은 패널로 묶고 관계·휴대폰 버튼은 오른쪽 위로 통일했다. 이 위치가 11·15의 기존 표현 차이를 해결하는 현재 구현 기준이다.

휴대폰은 둥근 기기 프레임, 상태 표시줄, 원형 프로필, 상대/나의 좌우 말풍선, 하단 5탭을 사용한다. 사진 카드에는 실제 파일의 썸네일이 나타나고 눌러 기존 확대 화면으로 이동한다. 수신 범위는 인물별로 유지하며 수치/사건/동의 판정은 변경하지 않는다. 논리 화면 1920×1080 기준 폰 프레임은 538×970이다. 다른 해상도에서의 폭넓은 반응형/접근성 검수는 추가 대상이다.

## 실제 변경

- `game/ui_design.rpy`: 공통 스타일, 9분할 둥근 패널, 원본 얼굴 크롭/원형 마스크, 화자별 스탠딩, UI 진입 효과.
- `game/screens.rpy`: 타이틀·대사·선택지·HUD·폰·사진·관계·저장/불러오기·설정·기록·알림·하루 결과 화면 스타일.
- `game/story_day01.rpy`: 화자 표시용 콜백만 연결하고 반복된 리아 3패널 초상 표시를 제거. 대사·선택지·분기·효과·슬롯 조건은 유지.
- `game/images/ui_v2`: UI 전용 도형·마스크·배터리 아이콘. 캐릭터 원화의 생성·편집 결과물이 아니다.
- `game/tests/ui_preview.rpy`: 시안 화면을 실제 게임에서 촬영하는 검수 경로.
- 기존 기능 검사의 스크린샷 시점은 UI 진입 효과 완료 후로 조정.

## 보존과 한계

히로인 원본4장의 SHA-256은 27의 승인 원본 지문과 같다. 캐릭터 디자인·파일·MASTER 승인은 변경하지 않았다. 게임은 동일한 실행용 원본 복사본을 표시한다. 리아 표정 시트/카페 CG는 여전히 예시·컨셉이며 최종 원화로 승격하지 않았다.

현재 인물 표시는 네 MASTER의 정지 스탠딩이다. 눈·입·머리의 독립 파츠 움직임은 이번 UI 작업으로 완성한 기능이 아니다. UI 진입 효과는 선택지 0.22초, 폰 0.28초이며 움직임 줄이기에서 0초로 표시한다. 새 캐릭터 표정·의상·단계 사진은 생성하지 않았다. 단계 사진은 실제 파일이 없으면 계속 미전송이다.

읽음 배지·OS 통신·실제 배터리 읽기·폰 자유입력 AI·본편2일 이후는 새로 구현하지 않았다. HUD·폰·저장 등 UI를 보강한 첫날 시안이며 출시용 완성 UI라고 단정하지 않는다.
