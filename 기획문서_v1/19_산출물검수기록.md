# 19. 산출물 검수 기록

검수일: 2026-10-01.

- 문서: README 포함19개를 우선 생성했고 이 검수 문서를 추가하여 현재20개다.
- 문서 링크: 로컬 Markdown 링크의 대상 존재 확인, 코드 블록 닫힘 확인 완료.
- 생성 파일: 표정 시트2048×768px, 카페 CG1672×941px. 카페 CG는 목표1920×1080 최종 자산이 아니라 생성 원본 예시다.
- 미리보기: 이미지 참조 경로와 JavaScript 문법 확인.
- 런타임: DOM 대체 환경에서 메시지·읽음·답장·일정·앨범·통화·저장 복원·프레임·초기화9항목 확인. 실제 브라우저 렌더링을 검증하는 테스트는 아니다.
- 로컬 서버: 페이지 HTTP200 응답 확인.
- 앱 내 브라우저: 환경 초기화 오류로 열리지 않아 실제 화면의 클릭·레이아웃 시각 검수는 완료하지 못했다.
- 이미지: 생성 결과를 눈으로 확인. 같은 캐릭터의 컨셉은 유지하지만 표정 시트의 위치·몸·입 차이가 있어 최종 애니메이션 원화로 확정하지 않았다.
- 완성 게임: 미구현. 미리보기는 기능 단면이고 루트·호감·날짜 전체가 연결되지 않았다.

미리보기 실행: `미리보기_v1/index.html`을 브라우저에서 열면 된다. 이미지가 같은 프로젝트 폴더에 있어야 한다. 연락 기록은 브라우저 로컬 저장소가 허용되는 경우에만 유지되며 실제 OS 연락을 사용하지 않는다.

## 2026-10-01 후속 메모 — 이전 기록과 현재 상태 구분

위 내용은 당시 산출물과 검수 결과로 보존한다. HTML 관련 폴더는 이후 사용자 요청으로 삭제되었으며 지금 실행 프로젝트는 26의 Ren’Py다. 삭제된 HTML 경로를 현재 열람 가능한 링크라고 표시하지 않는다. 네 승인 MASTER의 실제 경로·지문은 03·27에서 관리한다. 표정 시트와 카페 CG는 실제 파일을 다시 확인했지만 예시·컨셉 및 최종 원화 미승인 상태를 유지한다.
