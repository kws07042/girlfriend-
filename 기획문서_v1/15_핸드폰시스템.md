# 15. 핸드폰 시스템 — 실제 스마트폰처럼 보이는 게임 내 연락

## 1. 목적

캐릭터가 눈앞에 없을 때도 관계가 이어지는 감각을 만든다. 게임 화면의 핸드폰 버튼을 누르면 세로 스마트폰 화면이 열리고 문자·전화·사진·일정으로 인물의 사적 모습을 보여 준다. 모든 연락은 게임 내부의 허구 데이터이며 실제 전화·문자를 보내지 않는다.

## 2. 열기와 닫기

현재 UI v2의 화면 오른쪽 위 HUD 고정 버튼 또는 P키로 연다. 설정에서 키를 변경할 수 있게 한다. 열면 세계 장면은 35% 어두워지고 진행·자동 대사·스킵을 일시 정지한다. 닫으면 이전 대사와 입력 포커스로 돌아간다.

Esc·뒤로 버튼은 사진→대화방→목록→홈→닫기의 순서로 처리한다. 비용 있는 통화 중에는 '통화를 끝내고 닫기'를 확인한다. 전화 UI가 선택지 위에 겹쳐 양쪽에 클릭이 전달되지 않게 한다.

## 3. 화면 크기

1920×1080 기준 약 390×800 논리 픽셀의 폰을 오른쪽 또는 중앙에 표시한다. 1280×720에서는 화면 높이의 최대88%로 맞추고 내부 글자를 비례 축소만 하지 않는다. 작은 화면에서 '크게 보기' 모드로 중앙에 넓게 표시한다.

상단 상태바의 날짜·시간은 게임 시간이다. 실제 PC 배터리·연락처·위치·통신 정보를 읽지 않는다. 시간 표시는 오전09:00·점심12:30·저녁19:00을 기본값으로 하며 통화 소요 분은 연출용이다.

## 4. 앱 구조

| 앱 | 기능 |
|---|---|
| 메시지 | 캐릭터4명·TF 단체방, 읽음·답장·사진·일정 제안 |
| 전화 | 수신·발신·부재중·콜백·통화 기록 |
| 연락처 | 이름·직무·프로필·친밀도에 따른 소개 문구 |
| 사진 | 허락받아 저장한 사진·CG 일부 |
| 일정 | 업무 체크포인트·데이트 예약·변경 |
| 설정 | 폰 글자 크기·진동·소리·알림 미리보기 |

연락처의 사적 정보는 상대가 알려 준 뒤 추가된다. 호감이 높다고 주소와 개인정보가 자동 해금되지 않는다.

## 5. 홈 화면

상단: 게임 날짜와 간단한 인사. 중단: 앱6개. 하단: 최근 연락1건과 다음 약속. 잠금화면 연출은 가능하지만 비밀번호 입력 미니게임은 넣지 않는다. 폰 버튼에는 미확인 대화방 수를 표시하고 99+ 표기를 사용한다.

## 6. 메시지 화면

목록에는 프로필, 이름, 최근 문장, 게임 시각, 미확인 수. 대화방은 상대 말풍선 왼쪽·주인공 오른쪽, 날짜 구분선, 읽음·사진·선택형 답장 카드가 있다. 최신 메시지에 있을 때만 새 메시지 도착 시 자동 스크롤한다. 과거 대화를 읽는 중이면 '새 메시지' 버튼을 보여 준다.

입력창은 자유입력처럼 보이되 누르면 2~3개의 실제 답장 선택지를 연다. 기본 대본형 게임에서는 자유 텍스트에 자연스러운 대답을 무한 생성한다고 약속하지 않는다. 자유입력 AI 대화는 비용·저장·캐릭터 일관성까지 필요한 별도 확장안이다.

읽음은 대화방에서 해당 메시지가 표시되면 저장한다. 사진은 썸네일을 실제로 확인한 뒤 `photo_seen` 처리한다. 답장 보상은 메시지 ID당 한 번, 호감+1·하루 대상당 최대1이다. 긴 핵심 폰 사건은 별도 사건 보상을 사용해 중복하지 않는다.

## 7. 타이핑 연출

상대의 '입력 중…' 점은 대본상 지연을 표현한다. 실제 시간으로 약0.8~1.5초, 묶음 말풍선은 0.3~0.7초 간격을 초기 연출값으로 둔다. 빠르게 읽기·효과 줄이기 옵션에서는 즉시 출력한다. 앱을 닫아도 가짜 타이핑 상태가 영원히 남지 않도록 도착 시점을 게임 상태에 저장한다.

## 8. 전화

수신: 상대 이름·프로필·받기·나중에. 일반 전화는 폰 안 작은 배너, 핵심 전화는 게임 대사 사이 안전 지점에서 수신 화면을 연다. 실제 시간 타이머로 선택을 강요하지 않는다.

통화: 이름·게임 내 통화 경과·통화 대사·답변 선택·종료. 풀 보이스가 없어도 자막과 효과음으로 가능하다. 일반 안부 전화는 시간 비용0·능력치 보상0, 핵심 통화는 자유 저녁 슬롯1 비용을 시작 전에 안내한다.

'나중에'를 선택하면 부재중 기록과 콜백 버튼이 남는다. 거절한 즉시 호감이 떨어지지 않는다. 약속한 콜백을 지정일까지 하지 않았을 때만 약속 규칙을 적용한다. 콜백은 발신 가능한 시간대에만 열린다. 일반적으로 직장 연락은 오전·점심, 사적 핵심 연락은 저녁이다.

## 9. 약속 연결

문자에서 데이트 제안 수락 → 가능한 저녁 슬롯 선택 → 일정표와 메시지에 예약 카드 생성 → 본게임 다음 행동에 예약 표시. 수락만 했는데 시간이 배정되지 않은 상태는 '협의 중'으로 표시한다.

동일 슬롯 이중 예약은 막고 변경 카드를 제공한다. 취소에는 무조건 벌점을 주지 않고 합의 없는 불이행만 위반으로 처리한다. 전화로 변경한 일정도 같은 `promise_id`를 수정한다.

## 10. 사진과 앨범

사진 탭 → 폰 내부 확대 → 선택적 전체 화면 → 저장 또는 닫기. 저장하지 않아도 사건 보상은 같다. 저장 시 '게임 앨범에 저장'이라고 표기한다. OS 사진 폴더로 내보내기는 별도 명시적 기능이며 기본은 없다.

서윤: 책·차·작은 화분·서점. 리아: 커피·공연표·카페 일상·행사 준비. 유진: 전시·컵·무드보드·작업 일상. 지현: 야경·영화·산책길·퇴근 후 모습. 성인 분위기는 사적 취향과 신뢰로 전달한다.

## 11. 문자 말투

| 인물 | 리듬 | 예시 |
|---|---|---|
| 서윤 | 완결된 문장, 짧은 배려 | “오늘 맡아 준 부분 확인했어요. 고마워요. 내일은 내가 커피 살게요.” |
| 리아 | 짧은 문장2~3개, 가끔 이모지; 아래 반말은 사적 호칭·말투 전환 동의 후 | “발표 끝! / 이제 진짜 커피 마실 수 있다 / 너도 내려올래?” |
| 유진 | 적은 메시지, 구체적인 사진·감상 | “오늘 봤던 전시예요. 이 색은 실제로 보는 편이 좋겠네요.” |
| 지현 | 짧고 명확, 후반 감정 추가 | “내일 7시 괜찮아요? / 업무 이야기는 하지 않을 생각이에요.” |

리아는 05에 따라 초기에 ‘도현 씨’와 존댓말을 사용한다. 위 반말 예시는 사적 전환에 동의한 뒤 개인 연락에서만 적용한다. 친밀도 숫자나 사진 허용만으로 말투를 전환하지 않는다. 아래 RI01 후속 JSON은 초기 관계를 전제로 존댓말로 정리했고 ID·트리거·보상은 유지한다.

말투를 이모지 숫자로만 구분하지 않는다. 관계가 깊어지면 '알림 없이 보내기', 늦은 시간에 보내도 되는지 확인하는 대화가 생긴다.

## 12. 하루 연락 예시

1일 점심 전 리아의 커피 질문 → 점심 대화 뒤 사진 → 퇴근 전 지현의 업무 확인 → 저녁 행동 후 서윤의 짧은 감사. 하루에 장문 핵심 연락은 최대1개를 기본으로 하고 단문은 묶어 표시한다.

2주차 금요일에는 리아의 공연 제안을 받는다. 전화받기 또는 문자로 답해도 같은 약속 카드에 연결되고 친밀도 보상을 이중 지급하지 않는다.

## 14. 알림과 저장

알림 배지는 읽지 않은 대화방 수, 전화 앱 배지는 미확인 부재중 건수. 알림 내용 숨기기·효과음 끄기·진동 끄기 가능. 진동은 화면 내 기기 움직임일 뿐 실제 PC 하드웨어 진동을 요구하지 않는다.

저장: 메시지 순서·답장 선택·읽음·콜백·약속·사진 저장·스크롤 위치. UI 애니메이션의 중간 시점 대신 논리 상태를 저장한다. 불러오면 입력 중 연출은 안전하게 다시 시작하거나 즉시 완료한다.

## 15. 예시 범위

과거 HTML 예시는 폰 열기·대화·선택형 답장·사진 확대·부재중 콜백·통화 대사를 확인하는 단면이다. 본게임의 수치·루트·날짜 시스템 전체와 연결된 완성 구현은 아니었다. 해당 HTML은 삭제되었으며 현재 실행 범위는 아래 Ren’Py 절과 26을 따른다.

## Ren’Py 실제 화면과 본편 확장

현재 화면은 게임 HUD의 휴대폰 버튼을 눌러 연다. 문자/통화/사진/일정/수신5탭과 인물별 연락처4개가 있다. 답장 선택으로 점심 분기가 바뀌고, 전화 확인으로 카페/귀가 분기가 바뀐다. 카페 사진을 열고 저장표시를 남길 수 있으며 다음날 업무 약속은 일정 탭에 남는다.

친밀도 단계사진은25문서를 기준으로 한다. 수신 탭에서 인물별 최대단계를 설정한다. 기존 장소공유 카페사진은 단계사진과 다르다. 새 캐릭터 사진은 생성하지 않았으며 미제작 파일은 보내지 않는다.

## 2026-10-01 UI v2 후속 메모
