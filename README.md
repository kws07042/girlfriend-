# 퇴근 후, 우리 — Ren’Py 오피스 미연시

GitHub 사본에는 SDK 설치파일을 포함하지 않습니다. RenPy 8.5.3 SDK 설치 후 런처에서 RenPy_게임 프로젝트를 선택해 실행하세요. 또는 SDK를 도구/renpy-8.5.3-sdk에 배치하고 RenPy_게임시작.bat를 실행하세요.

- 실제 게임: `RenPy_게임` — 첫 주 1~5일차, 네 인물의 발견 사건·목표 합의, 휴대폰 문자·전화·사진·일정, 저장·불러오기.
- 기획 문서: `기획문서_v1` — 인물 설정, 6주 스토리, 관계·시간 시스템, 성인 로맨스 연출과 단계 사진.
- 사용자 배경 원본: `backgrounds` / `backgrounds_styled`. 실행용은 `RenPy_게임/game/images/bg`; `배경동기화.ps1`로 갱신합니다.
- 단계 사진 연결 자리: `RenPy_게임/game/images/phone`. 단계 사진은 이번 작업에서 생성하지 않았고, 프로필은 사용자 제공 4개 사진을 적용했습니다.
- 검수 결과: `기획문서_v1/26_RenPy전환검수.md`.

HTML 관련 프로젝트 폴더는 삭제했습니다. 현재 플레이는 5일차까지이고, 6일 이후 본편은 제작 예정입니다. 히로인 루트 선택 계획은 15일차 저녁입니다.

현재 문서 목록과 분야별 기준: [기획 문서 목차](기획문서_v1/README.md). 캐릭터 승인 외형: [03 MASTER 대응](기획문서_v1/03_캐릭터비교와관계.md). 이번 MD 동기화 결과·보류 항목: [27 검수 보고](기획문서_v1/27_MASTER동기화검수.md).

캐릭터 MASTER 원본 폴더: `히로인` — `한서윤_seoyun_MASTER.png`, `강리아_ria_MASTER.png`, `차유진_yujin_MASTER.png`, `백지현_jihyun_MASTER.png`. 현재 승인 대응은 03을 참조합니다.

현재 UI 시안 v2: [실제 게임 화면 미리보기](UI_시안_v2/README.md). 대사·선택지·휴대폰·저장 UI에 적용했으며 [28 검수](기획문서_v1/28_RenPy_UI보강시안.md)에 변경과 한계를 기록했습니다.
