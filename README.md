# 퇴근 후, 우리 — 프로젝트 안내

2026-10-11 최신 이미지: 네 명의 원화 46장·업스케일 46장을 전체 검수했습니다. 백지현은 선택된 2번 애쉬베이지 웨이브·보라회색 눈 외형으로 마스터·모든 포즈·표정을 교체했습니다. 내려놓은 손의 손가락/손톱과 유진 한쪽 귀걸이를 다듬고 게임용 46파일도 갱신했습니다. [전체 검수·최신 미리보기](미리보기/전체히로인_검수_v12/README.md)

게임은 **RenPy_게임시작.bat**로 실행하세요. 현재 **DAY 01~30 본편**까지 플레이할 수 있습니다. 첫 주는 네 사람과의 공통 만남이며 두 번째 주부터 관심 대상을 고르고 대화·신뢰에 따라 변경할 수 있습니다. 정리된 히로인 폴더의 최신 이미지를 실행용 경로에 다시 연결했습니다.

최근 작업: [네 히로인 정면 MASTER·포즈·표정·2배 확대본](히로인/README.md). 리아의 인사·솔직한 대화 자세와 세 인물의 듣는 자세를 실제 대사에 연결했습니다. 이전 캐릭터 작화·사복·비교·다운로드 이미지를 제거하고 게임 파일을 새 작화로 교체했습니다.

배경을 교체하려면 원본자료/배경 안의 사용자원본 또는 그림체보정에 넣고 **배경동기화.ps1**을 실행하세요. 같은 파일명은 수정 시각이 최신인 원본을 게임에 복사합니다.

2026-10-07 정리에서 파일을 삭제하지 않았습니다. 게임의 이미지 경로와 실행 버튼 위치를 유지하고, 예전 작업물만 용도별로 이동했습니다. [정리 기록](폴더정리_안내.md)에 원래 위치와 새 위치가 있습니다.

## GitHub에서 내려받아 실행하기

Ren’Py SDK·개인 세이브·캐시·변경 전 백업은 저장소에 포함하지 않습니다. 공식 [Ren’Py 다운로드](https://www.renpy.org/download.html)에서 SDK를 받고, 프로젝트에서 검수한 8.5.3 SDK 폴더를 `도구/renpy-8.5.3-sdk`에 두면 Windows 실행 버튼을 사용할 수 있습니다. 다른 환경에서는 Ren’Py Launcher에서 `RenPy_게임` 프로젝트를 열면 됩니다.

네 개인 경로와 팀 경로는 6주차 엔딩까지 연결했습니다. 복수 관계 경로는 별도 제작 중입니다. DAY 11 방향 선택과 DAY 15 루트 선택만으로 교제가 자동 확정되지는 않습니다. 이전 사복 이미지는 제거했습니다. 해당 장면은 인물별 새 마스터를 사용합니다.

최근 적용: [3·4주차 구현과 임시 장면](기획문서_v1/37_3_4주차구현과임시장면.md).
