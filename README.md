# 퇴근 후, 우리 — 프로젝트 안내

게임은 **RenPy_게임시작.bat**로 실행하세요. 현재 **DAY 01~20 본편**까지 플레이할 수 있습니다. 첫 주는 네 사람과의 공통 만남이며 두 번째 주부터 관심 대상을 고르고 대화·신뢰에 따라 변경할 수 있습니다.

| 찾는 것 | 위치 |
|---|---|
| 게임 코드와 실제 실행 이미지 | RenPy_게임/game |
| 승인된 네 명의 MASTER와 최신 24장 후보 | [히로인 안내](히로인/README.md) |
| 캐릭터·스토리·시스템 기획 | [기획문서 목차](기획문서_v1/README.md) |
| 배경·메신저 프로필·보존 원화·Live2D 준비 자료 | [원본자료 안내](원본자료/README.md) |
| 예전 시안·생성 후보·수정 과정·옛 미리보기 | [보관자료 안내](보관자료/README.md) |
| 적용 문서와 검수 로그 | [게임 기록 안내](RenPy_게임/기록/README.md) |
| 변경 전 파일 백업 | 변경백업 |
| 실행에 필요한 Ren’Py SDK | 도구 |

최근 작업: [첫 주 공통과 관심 변경](RenPy_게임/기록/적용문서/첫주공통과관심변경_적용_20261007.md), [사복 16장과 업스케일](히로인/사복16장_20261008_v1/README.md).

배경을 교체하려면 원본자료/배경 안의 사용자원본 또는 그림체보정에 넣고 **배경동기화.ps1**을 실행하세요. 같은 파일명은 수정 시각이 최신인 원본을 게임에 복사합니다.

2026-10-07 정리에서 파일을 삭제하지 않았습니다. 게임의 이미지 경로와 실행 버튼 위치를 유지하고, 예전 작업물만 용도별로 이동했습니다. [정리 기록](폴더정리_안내.md)에 원래 위치와 새 위치가 있습니다.

## GitHub에서 내려받아 실행하기

Ren’Py SDK·개인 세이브·캐시·변경 전 백업은 저장소에 포함하지 않습니다. 공식 [Ren’Py 다운로드](https://www.renpy.org/download.html)에서 SDK를 받고, 프로젝트에서 검수한 8.5.3 SDK 폴더를 `도구/renpy-8.5.3-sdk`에 두면 Windows 실행 버튼을 사용할 수 있습니다. 다른 환경에서는 Ren’Py Launcher에서 `RenPy_게임` 프로젝트를 열면 됩니다.

5·6주차 본편과 복수 관계 경로는 제작 중입니다. DAY 11 방향 선택과 DAY 15 루트 선택만으로 교제가 자동 확정되지는 않습니다. 사복 16장은 4주차 개인 저녁에 적용했고 새 진지 표정은 후보 상태입니다.

최근 적용: [3·4주차 구현과 임시 장면](기획문서_v1/37_3_4주차구현과임시장면.md).
