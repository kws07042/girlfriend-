## 게임 실행

Windows에서는 RenPy_게임시작.bat로 실행합니다. 현재 DAY 01~30 본편과 6주차 개인·팀 엔딩이 연결되어 있으며 복수 관계 경로는 별도 제작 중입니다. 이전 사복 장면은 현재 인물별 마스터를 사용합니다.

Ren’Py SDK·개인 세이브·캐시·변경 전 백업은 저장소에 포함하지 않습니다. 검수된 8.5.3 SDK 폴더를 도구/renpy-8.5.3-sdk에 두거나 Ren’Py Launcher에서 RenPy_게임 프로젝트를 엽니다. [Ren’Py 다운로드](https://www.renpy.org/download.html).

배경을 교체하려면 원본자료/배경의 사용자원본 또는 그림체보정에 같은 파일명으로 넣고 배경동기화.ps1을 실행합니다. 실행에 쓰는 배경·UI와 배경 원본은 유지했습니다.
