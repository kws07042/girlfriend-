# 퇴근 후, 우리 — 프로젝트 안내

Ren’Py 비주얼 노벨 프로젝트입니다. 사용자의 요청에 따라 GitHub 저장소와 이 프로젝트의 이미지 보관 영역에서 한서윤·차유진·백지현의 캐릭터 이미지를 제거했습니다. 강리아 이미지와 배경·UI 자료는 유지했습니다. 이미지가 제거된 인물의 스토리와 설정 문서는 남아 있으며, 게임은 해당 스프라이트가 없을 때 빈 투명 영역과 기본 프로필 색상을 사용합니다.

|찾는 것|위치|
|---|---|
|강리아 이미지 및 캐릭터 문서|[히로인](히로인/README.md)|
|게임 코드와 배경·UI|RenPy_게임/game|
|캐릭터·스토리·시스템 기획|[기획문서](기획문서_v1/README.md)|
|배경 원본과 동기화 자료|[원본자료](원본자료/README.md)|

저장소에는 배경과 UI 이미지가 유지되어 있습니다. Windows에서는 RenPy_게임시작.bat로 실행할 수 있습니다.
