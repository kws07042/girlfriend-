# 손가락·손톱 수정 — 2026-10-08

9개 포즈에 해당하는 PNG 20개를 수정했습니다. 원화·업스케일·기본/진지 표정 및 동일한 MASTER 복사본에 반영했습니다.

손가락 관절과 겹침, 뾰족한 손끝, 손톱의 형태와 방향을 정리했습니다. 손바닥이 보이는 포즈에는 손톱이 보이지 않도록 했습니다.

## 검증 및 범위

- 최종 저장된 PNG를 확대하여 손가락·손톱·손목 연결을 확인했습니다. 밝은 배경과 어두운 배경에서 투명 경계를 확인했습니다.
- 이미지 크기와 투명 배경을 유지했습니다. PNG 20개 모두 손 주변 지정 영역 밖 RGBA 픽셀 변경은 0입니다. 지정 영역에는 손목과 인접 배경 일부가 포함됩니다. 유진 업무의 턱 근처 손은 후속 검수에서 추가 수정했으며 추가 영역은 검증 JSON에 기록했습니다.
- [픽셀 검증](픽셀검증.json), [수정 파일·해시 목록](수정파일.json), [편집 프롬프트 명세](프롬프트.md)
- 최초 수정은 히로인 폴더에 적용했습니다. 이후 [인게임 포즈 검수](../포즈/README.md)에서 추가 포즈 5장에도 같은 수정본을 반영했습니다. 이후 외부 이미지 정리에서 게임용 원래 경로는 삭제했고, 현재 보존본은 히로인 폴더에 있습니다.
- 수정 전 손이 들어 있는 JPG 15개와 이전 ZIP 2개를 현재 폴더에서 삭제했습니다. 현재 수정본은 원래 경로의 PNG를 기준으로 확인하세요.
