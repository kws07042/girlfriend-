# 히로인 표정 24장 · 귀걸이 국소 통일 v2

기본 12장 + 진지 12장, 총 24장. 직전 v1의 표정·전신은 유지하고 귀와 귀걸이 부분만 수정했다. 새로운 전신 생성이나 업스케일 재생성은 하지 않았다.

| 히로인 | 통일 기준 |
|---|---|
| 서윤 | 승인된 매끈한 맨 귓불. 귀걸이를 추가하지 않았다. |
| 리아 | 매끄러운 귓불 + 얇은 금색 타원 링. 귓불의 살색 돌기를 제거했다. |
| 유진 | 작은 금색 고정부 + 금색 물방울 펜던트. 포즈별 윗부분과 펜던트 모양을 맞췄다. |
| 지현 | 한 개의 작은 흰 진주 스터드. 여러 알처럼 붙어 보이던 윤곽을 정리했다. |

각 히로인의 MASTER 귀 디자인을 바탕으로 built-in image_gen에서 귀 확대 영역만 편집했다. 해당 인물의 세 포즈 모두에 같은 국소 결과를 정렬해 반영했다. 같은 포즈에서 기본/진지로 바뀌어도 귀걸이가 바뀌지 않도록 두 표정에도 동일하게 적용했다. 서윤은 이미 귀걸이가 없는 승인 원화라서 세 포즈 모두 그대로 보존했다.

수정 영역 밖 RGBA 픽셀 차이 0, 투명도 차이 0. 눈·입·표정·턱·옷·몸·손과 전신 색감은 v1과 같다. 해상도는 서윤 2048×3070, 다른 인물 2048×3072. 파일 색 정보도 보존했다. 새 진지 표정 세트는 별도 저장본이다. 귀와 귀걸이 국소 수정은 원본 MASTER 3장과 기존 게임용 이미지 10장(MASTER 3장, 추가 포즈 7장)에 반영했다. 서윤은 승인된 맨 귓불 그대로 보존했다. 눈 깜빡임이나 얼굴 합성 기능은 추가하지 않았다.

귀_프롬프트.json에는 국소 편집 프롬프트 3개, 입력과 생성 결과 경로가 있다. 생성_프롬프트.json은 v1 표정 제작 12개 기록이다. manifest.json은 포즈별 원화·수정 전·수정 후 경로, 귀 편집 영역과 정렬을 기록한다. 귀_픽셀검증.json과 완료_검수.json에 보존 검증 결과를 저장했다.

## MASTER 갱신

원본 MASTER는 히로인 폴더의 기존 파일명으로 저장했다. MASTER_수정본에는 네 명의 현재 MASTER 사본이 있다. 게임용 MASTER와 기존 포즈의 귀걸이도 같은 기준으로 갱신했다. 기존 얼굴·몸·옷·손·투명도를 보존했고, 수정 영역 밖 픽셀 차이는 0이다. MASTER_적용검수.json에 수정 경로·백업·검증을 기록했다.
