## 검증 및 범위

- 최종 저장된 PNG를 확대하여 손가락·손톱·손목 연결을 확인했습니다. 밝은 배경과 어두운 배경에서 투명 경계를 확인했습니다.
- 이미지 크기와 투명 배경을 유지했습니다. PNG 20개 모두 손 주변 지정 영역 밖 RGBA 픽셀 변경은 0입니다. 지정 영역에는 손목과 인접 배경 일부가 포함됩니다.
