# 한서윤 새 마스터 기준 작화

정면 MASTER 1장, 포즈 3장, 기본·진지 표정 6장을 새 마스터의 얼굴·선화·채색·전신 비율에 맞춰 제작했습니다. 귀·귀걸이·눈·손·옷·신발을 확대/전신 비교로 확인했습니다. 귀걸이를 제거하고 맨 귓불로 변경했습니다. 얼굴·몸의 명암과 선을 같은 마스터로 통일했습니다. 생성형 편집으로 미세한 형태 차이는 있습니다. 기본 표정은 해당 포즈와 같은 파일입니다.

원화 1024×1536, 확대본 2048×3072의 투명 PNG입니다. 확대는 Lanczos3 리샘플링으로 새 디테일을 임의 생성하지 않았습니다.

얼굴 개성 차별화: 긴 타원형 윤곽, 부드러운 눈꼬리와 곡선 눈썹, 따뜻한 미소. 얼굴 부분은 내장 image_gen으로 편집하고 기존 전신에 국소 적용했습니다. 유진의 턱을 짚는 자세는 손가락 접촉을 별도로 편집했습니다. 30장 전체에서 편집 사각형 밖 RGB와 전체 alpha가 이전 파일과 동일한지 검사했습니다. 얼굴형·눈매·눈썹·이목구비 간격을 구분했고 같은 작화 방식은 유지했습니다.

대표 포즈 추가: 다정한 미소와 자리를 권하는 손짓. 얼굴·귀·귀걸이·손·손톱과 전신 작화를 확대 비교했습니다. 원화 1024×1536, 2배 확대본 2048×3072이며 게임에는 확대본을 연결했습니다. 내장 image_gen 사용. 생성형 편집으로 포즈별 미세한 형태 차이가 있습니다.

최신 변경: 양쪽 귀걸이를 제거한 맨 귓불. 기존 얼굴·표정·전신 유지. 내장 image_gen 국소 편집이며 전신은 보존했습니다.
