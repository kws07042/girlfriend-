# 한서윤 새 마스터 기준 작화

정면 MASTER 1장, 포즈 3장, 기본·진지 표정 6장을 새 마스터의 얼굴·선화·채색·전신 비율에 맞춰 제작했습니다. 귀·귀걸이·눈·손·옷·신발을 확대/전신 비교로 확인했습니다. 귀걸이는 금색 링 디자인을 유지했습니다. 얼굴·몸의 명암과 선을 같은 마스터로 통일했습니다. 생성형 편집으로 미세한 형태 차이는 있습니다. 기본 표정은 해당 포즈와 같은 파일입니다.

원화 1024×1536, 확대본 2048×3072의 투명 PNG입니다. 확대는 Lanczos3 리샘플링으로 새 디테일을 임의 생성하지 않았습니다.

재제작 검수: 이전 얼굴 묘사를 보존하던 방식에서 벗어나 강리아의 넓고 부드러운 눈, 작은 코, 선으로 표현한 입, 절제된 전신 명암을 기준으로 다시 생성했습니다. 세 인물의 신발에 강한 흰 반사띠가 남지 않도록 했으며, 한서윤 로퍼는 확대 생성 편집 후 해당 부분만 적용했습니다. 머리색·눈색·복장·귀걸이 디자인은 유지했습니다.
