# 히로인 이미지

요청에 따라 한서윤·차유진·백지현의 캐릭터 이미지를 저장소에서 제거했습니다. 강리아 이미지는 유지했습니다. 배경과 UI 자료는 그대로 보존되어 있습니다.

|인물|이미지 상태|
|---|---|
|[강리아](강리아/README.md)|이미지 유지|
|[한서윤](한서윤/README.md)|캐릭터 이미지 제거됨|
|[차유진](차유진/README.md)|캐릭터 이미지 제거됨|
|[백지현](백지현/README.md)|캐릭터 이미지 제거됨|

게임의 스토리와 인물 설정은 유지됩니다. 제거한 인물의 스프라이트와 프로필 이미지는 표시하지 않으며, 이미지가 없어도 UI가 오류를 내지 않도록 처리했습니다.
