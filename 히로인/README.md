재제작: 한서윤·차유진·백지현의 얼굴 디자인과 전신 마무리를 강리아 기준으로 다시 조정했습니다. 강리아의 기준 원화·포즈·표정은 유지했습니다.

얼굴 개성 갱신: 리아는 그대로 두고 서윤은 길고 부드러운 윤곽, 유진은 보라색 눈과 부드러운 눈매·턱선, 지현은 부드러운 턱선과 또렷한 갈색 눈매로 구분했습니다. 공통 작화와 전신은 유지했습니다.

현재 이미지: 네 히로인의 화장을 제거하고 백지현의 눈매·턱선·미소를 개선했습니다. MASTER·포즈·표정·2배 확대본과 게임용 파일 전체에 반영했습니다.

차유진 현재 이미지: 눈꼬리 각도와 눈썹·턱 끝을 부드럽게 다듬고, 같은 무화장 얼굴을 MASTER·포즈·표정·2배 확대본과 게임용 파일에 적용했습니다.

인물별 대표 표정·몸짓: 리아는 활기, 서윤은 다정함, 유진은 여유, 지현은 자신감을 강조했습니다. 대표 포즈 4장과 2배 확대본을 추가해 게임의 긍정적인 대사 총 8곳에 연결했습니다. 위 미리보기는 새 대표 포즈입니다.
