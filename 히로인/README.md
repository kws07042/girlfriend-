원화는 1024×1536 투명 PNG, 확대본은 2048×3072입니다. 확대는 Lanczos3 리샘플링으로 새 디테일을 생성하지 않습니다. 생성형 편집으로 포즈별 미세한 형태 차이가 있습니다.

재제작: 한서윤·차유진·백지현의 얼굴 디자인과 전신 마무리를 강리아 기준으로 다시 조정했습니다. 강리아의 기준 원화·포즈·표정은 유지했습니다.

얼굴 개성 갱신: 리아는 그대로 두고 서윤은 길고 부드러운 윤곽, 유진은 좁고 올라간 눈매와 턱선, 지현은 곧은 눈썹과 넓은 아래 얼굴로 구분했습니다. 공통 작화와 전신은 유지했습니다.

현재 이미지에는 인물별 화장도 적용되어 있습니다: 리아 코랄·피치, 서윤 피치·베이지, 유진 모브·토프, 지현 로즈·브라운. 캐릭터별 얼굴 설계와 공통 작화, 포즈·표정은 유지했습니다.
