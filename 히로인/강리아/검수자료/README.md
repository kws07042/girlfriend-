# 새 마스터 기준 작화 검수

MASTER·포즈 3장·표정 6장을 같은 마스터의 얼굴, 선화, 색감, 피부·옷·신발 명암에 맞춰 제작했습니다. 귀 부분은 확대 생성 편집 후 해당 부위만 합성했습니다. 이전 생성본의 귓불 돌기와 중복 링을 수정했습니다.

각 포즈와 진지 표정의 얼굴·몸·손·의상·신발을 비교했습니다. 보이는 귀의 귓불은 매끈한 단일 윤곽이며 금색 링은 한 개입니다. 반대편 귀는 머리카락에 가려져 전체를 확인할 수 없습니다. 손가락은 포즈와 소품에 따라 일부 가려집니다. 생성형 편집으로 포즈별 미세한 형태 차이가 있습니다.

원화는 1024×1536, 확대본은 2048×3072의 투명 PNG입니다. 확대는 Lanczos3 리샘플링으로 작화를 유지하며 새 디테일을 생성하지 않았습니다. 기본 표정은 해당 MASTER/포즈와 동일한 파일을 재사용했습니다.

전신10장.jpg · 얼굴10장.jpg · 귀걸이확대.png · 손확대.png를 실제 저장 결과에서 만들었습니다. 파일정보.json에 해시와 투명 배경 확인 결과, 제작프롬프트.json에 실제 프롬프트를 기록했습니다.
