# 백지현 얼굴 재설계 · 2026-10-11

원화 11장: MASTER 1장·포즈 4장·기본/진지 표정 6장. 더 열린 호박색 눈매와 차분한 닫힌 미소로 같은 그림체와 체형에 어울리는 성숙한 얼굴을 설계했습니다. 얼굴·귀·진주 스터드와 포즈별 접합부를 확대 비교했습니다. 대표 포즈는 원래 고개 각도에 맞춰 눈·눈썹·코·입을 국소 정렬하고 턱·머리카락·목 경계를 보존했습니다. 생성형 편집으로 포즈별 미세한 형태 차이는 있습니다.
