# 백지현 새 마스터 기준 작화

정면 MASTER 1장, 포즈 3장, 기본·진지 표정 6장을 새 마스터의 얼굴·선화·채색·전신 비율에 맞춰 제작했습니다. 귀·귀걸이·눈·손·옷·신발을 확대/전신 비교로 확인했습니다. 귀걸이는 흰 진주 스터드 디자인을 유지했습니다. 얼굴·몸의 명암과 선을 같은 마스터로 통일했습니다. 생성형 편집으로 미세한 형태 차이는 있습니다. 기본 표정은 해당 포즈와 같은 파일입니다. 캐주얼은 정면 MASTER의 편하게 선 자세를 재사용했습니다.

원화 1024×1536, 확대본 2048×3072의 투명 PNG입니다. 확대는 Lanczos3 리샘플링으로 새 디테일을 임의 생성하지 않았습니다.

얼굴 개성 차별화: 넓어진 아래 얼굴과 턱, 곧은 눈썹과 또렷한 눈꺼풀, 차분한 입매. 얼굴 부분은 내장 image_gen으로 편집하고 기존 전신에 국소 적용했습니다. 유진의 턱을 짚는 자세는 손가락 접촉을 별도로 편집했습니다. 30장 전체에서 편집 사각형 밖 RGB와 전체 alpha가 이전 파일과 동일한지 검사했습니다. 얼굴형·눈매·눈썹·이목구비 간격을 구분했고 같은 작화 방식은 유지했습니다.
