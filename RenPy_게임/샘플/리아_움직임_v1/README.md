# 리아 움직임 미리보기

8초 반복 샘플. 실제 RenPy 게임에서 동일 장면과 포즈를 고정한 뒤 눈과 머리 움직임을 기록했습니다.

- GIF: 빠르게 재생해 볼 수 있는 확대 미리보기. 256색 미리보기입니다.
- 확대 PNG / 게임화면 PNG: 색 손실 없는 APNG 애니메이션입니다.
- 검수.json: 눈 밖 변화와 아래 몸통/팔/커피 고정 검증 결과입니다.

설정의 캐릭터 움직임으로 켜고 끌 수 있습니다. 움직임 줄이기가 우선합니다.
