# 퇴근 후, 우리 — 4주차까지 진행 버전

현재 DAY 01~20 본편까지 진행합니다. 1920×1080 기준이며 창 크기는 엔진에서 조절할 수 있습니다.

- 첫 주: 네 사람의 직무·말투·취향을 함께 알아갑니다. 대화 태도와 업무 판단은 선택하지만 상대를 고르지 않습니다.
- 두 번째 주: 관심 대상을 고르고 다른 사람과도 대화합니다. 서로 다른 날짜의 대화·자기 경험 공유·신뢰가 쌓이면 플레이어가 관심을 변경할 수 있습니다.
- 세 번째 주: 방향 선택 뒤 개인 핵심 사건과 고객 범위를 확인하고 DAY 15에 조건을 만족한 개인 루트 또는 팀을 선택합니다.
- 네 번째 주: 사복 만남·관계 공개 범위·교제 수락/유보/친구를 확인합니다. 사진 없는 임시 구간은 별도의 선택으로 열립니다.
- 5·6주차와 복수 관계 본편은 제작 중입니다.

선택형 문자·수신 전화·통화 종료 반응·자료 약속·저장과 복원·기록·자동 진행·롤백을 제공합니다. 실시간 채팅 서비스나 실제 음성 통화는 아닙니다.

승인된 MASTER·업무·편한 대화·듣는 포즈와 배경을 사용합니다. 피부·머리색 보정과 잔상 방지 전환을 유지하며, 이목구비 합성·눈 깜빡임·몸 흔들기는 사용하지 않습니다. Live2D 완성 모델은 아직 적용하지 않았습니다.

원본·사복 16장·24장 표정 후보는 상위 [히로인 폴더](../히로인/README.md)에 있습니다. 사복 16장은 4주차 개인 저녁에 연결했고 새 진지 표정은 후보입니다.

## 실행

공식 Ren’Py SDK를 별도로 준비하세요. 상위 `도구/renpy-8.5.3-sdk`에 검수한 SDK를 두고 `RenPy_게임시작.bat`를 실행하거나, Ren’Py Launcher에서 이 프로젝트를 열면 됩니다. [프로젝트 안내](../README.md).

배경 원본은 `원본자료/배경`에 있고 실행용은 `game/images/bg`에 있습니다. 상위 `배경동기화.ps1`로 갱신합니다.
