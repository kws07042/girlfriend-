# B/C 대화 구도

- B: 평상시 대화·업무·단체 대화. 인물을 화면 중앙에서 조금 오른쪽에 크게 배치한다.
- C: 속마음을 드러내는 지정 대사에서 상반신을 확대한다. 주인공의 답변과 선택지에서도 유지한다.
- 장소 또는 이야기 라벨이 바뀌거나 다른 여성 캐릭터가 말하면 B로 복귀한다.
- 휴대폰이 열린 동안은 인물 이미지를 숨긴다. 닫으면 현재 B/C 구도로 돌아온다.
- MASTER 이미지는 수정하지 않았다. 2026-10-02 후속 요청으로 문자 뒤 만나는 장면의 도착 인사를 story_day01.rpy, story_week01.rpy, week_phone.rpy에 추가했다.

구현: game/ui_camera_bc.rpy. 기존 say/choice/quick_menu/office_portrait 화면을 늦은 초기화 단계에서 교체한다. 따라서 해당 화면을 수정할 때는 이 파일을 확인해야 한다.

현재 C 적용 지점: 첫날 카페에서 리아의 인정받고 싶은 마음, 둘째 날 서윤의 혼자 맡아온 일, 셋째 날 리아의 캠페인 실패, 넷째 날 유진의 작업을 남기고 싶은 이유. 지현의 현재 업무 대화는 B를 유지한다.

스토리 작업자가 장면을 명시하려면 `$ ui_camera_set("C")`, 일상으로 돌아가면 `$ ui_camera_set("B")`, 자동 판정으로 돌아가면 `$ ui_camera_set()`을 사용한다. 명시 지정은 해제할 때까지 유지된다.

자동 판정은 ui_camera_close_beats에 있는 정확한 대사를 기준으로 한다. 스토리 작업에서 그 문장을 바꾸면 해당 목록도 갱신하거나 명시 지정을 사용한다. 새 대사는 기본 B로 표시한다.

검증: office_bc_camera 테스트에서 B 기본값, 감정 선택지의 C 유지, 분기 후 C, 장면 종료 후 B와 휴대폰 화면을 확인한다. 기존 이미지 비교 테스트는 이전 UI 기준 이미지와 차이가 발생하므로 별도 갱신이 필요하다.



## 통화 전용 화면 (2026-10-02)

- game/ui_phone_call.rpy가 통화 중 화면을 표시한다. 휴대폰은 위쪽 중앙에 72% 크기로 배치해 하단 대화창(850px부터)과 겹치지 않는다. 선택지는 기존 왼쪽 구도를 사용한다.
- 통화 중에는 MASTER 인물을 숨기고 작은 연락처 프로필, 상대 이름, 통화 시간, 대화 기록, 통화 종료 버튼을 표시한다.
- 현재 연결된 통화는 첫날 리아, 둘째 날 서윤, 넷째 날 유진이다. 원래 대사는 유지한다.
- 신규 통화는 ui_phone_call_begin(캐릭터 키, 종료 시 이동할 라벨)로 시작하고, 정상 종료 지점에서 ui_phone_call_end()를 호출한다. 종료 버튼의 도착 라벨에서도 종료 함수를 호출해야 한다.
- 통화 중 문자 화면을 다시 열지 못하도록 휴대폰 버튼과 P키를 막는다. 대화 기록과 저장·불러오기는 사용할 수 있다.
- office_active_call: 실제 수신 후 통화 화면, 대사와 선택지, 저장·불러오기, 서윤 정상 종료, 유진 종료 버튼을 검증했다. 11개 검증 항목 통과.


## 답장 상대 표시 (2026-10-02)

- 답장을 보낼 상대 안내 문구를 제거했다. 문자 화면의 연락처 이름 오른쪽 위에 작은 빨간 점을 표시한다.
- 빨간 점: 답장할 메시지가 있다. 1.3초 주기로 밝기만 천천히 변하며, 읽어도 유지되고 답장을 보내면 사라진다. 필수 답장이 있는 장면은 그 상대를 우선 안내한다.
- 안 읽은 메시지에도 같은 빨간 점이 천천히 깜박인다. 답장할 메시지가 없으면 읽었을 때 사라진다.
- 움직임 줄이기 설정에서는 빨간 점도 고정한다. 수신 설정 화면에는 답장 점을 표시하지 않는다.
- 구현은 game/phone_reply_ui.rpy와 screens.rpy의 연락처 줄에 있다. office_reply_marker 테스트로 다른 상대 선택, 읽음과 답장 구분, 점 해제와 진행을 확인했다.
- 장소 전환 검토: 현재 장소 배경 교체와 화자/B/C 구도 변경에 전환 효과가 없다. 장소 이동은 약 0.4초 화면 겹치기, 큰 시간 이동은 짧은 암전, 인물과 구도는 약 0.2~0.3초 전환을 권장한다. 이번 요청에서는 비교와 검토만 했으며 장소 연출은 아직 변경하지 않았다.



## 전화 수신 자동 표시 (2026-10-02)

- 전화 수신 시 phone 화면은 처음부터 통화 탭과 실제 발신자로 열린다. 이미 휴대폰이 열려 있어도 수신 중에는 통화 탭으로 전환한다.
- 수신 중에는 계속 버튼을 비활성화한다. 받기 또는 지금은 받지 않기로 선택해야 한다.
- 첫날 리아 전화에서도 발신자와 연락처를 명시해 이전 통화 상대와 혼동하지 않게 했다.
- 연락처 이름 옆의 미확인 숫자는 제거하고 빨간 점으로 통일했다. 점은 이름 오른쪽 위 6px 크기이며 선택된 이름 배경 위에도 표시한다.
