# 포즈/표정 연결과 리아 움직임 적용

2026-10-06 / 요청한 1번 연결 이후 3번 리아 샘플 제작 완료.

## 게임에서 달라진 점

- 채택된 포즈 9종을 실제 게임 에셋으로 등록했습니다.
- 서윤: 업무는 태블릿 설명, 휴식/개인 대화는 손을 편하게 모은 포즈.
- 리아: 첫 커피 인사는 기본 포즈, 업무 자료 설명은 손짓, 라운지/카페 대화는 두 손 커피, 카페에서 속내를 말할 때는 커피를 내린 포즈.
- 유진: 업무는 시안 보드, 개인 대화/퇴근 후 정리는 머리를 가볍게 만지는 포즈.
- 지현: 업무는 손짓, 퇴근 인사는 팔을 편하게 내린 포즈.
- 같은 상대와 같은 장소에서 포즈가 바뀔 때 0.18초로 짧게 전환합니다. 대사마다 포즈를 바꾸지 않습니다.
- 눈/눈썹/입을 MASTER 기반 표정에서 따로 합성해, 포즈 생성 과정의 얼굴 차이가 계속 바뀌지 않도록 했습니다. 머리카락에 사각 합성 경계가 생기지 않게 얼굴 마스크를 특징 부위 중심으로 좁혔습니다.
- 기존 저장을 불러올 때 포즈 상태를 복원하며, 과도기 전환은 완료 상태로 표시합니다.
- 스토리 대사 파일은 작업 전후 해시가 동일합니다.

## 리아 움직임

- 눈: 원래 눈 → 반쯤 감김 → 감김 → 반쯤 감김 → 원래 눈. 짧은 깜빡임과 드문 두 번 깜빡임.
- 머리: 목 부위로 갈수록 줄어드는 작은 회전/이동. 최대 회전 약 0.23도, 머리 부분 이동은 원본 기준 수 픽셀.
- 입과 표정은 현재 대사의 상태를 유지하며, 눈 프레임만 눈 영역에 덧씌웁니다.
- 현재 리아 한 명에만 적용한 샘플입니다. 게임에서 기본 켜짐.
- 설정 → 캐릭터 움직임에서 끌 수 있습니다. 움직임 줄이기를 켜면 이 움직임도 정지합니다.
- 휴대폰/통화/저장/설정 등의 화면에서는 멈추거나 캐릭터를 숨깁니다.
- 실제 게임 화면으로 8초 미리보기를 기록했습니다. 재생용 GIF와 색 손실 없는 APNG를 저장했습니다.
- 내장 image_gen으로 눈 프레임 2장 제작 후 눈 영역만 사용했습니다. 생성 원본/정확한 프롬프트는 보관자료/02_히로인_이전작업/리아_애니메이션_v1/생성프롬프트.json에 보관합니다.
- 머리 변형은 RenPy의 [모델 기반 렌더링](https://www.renpy.org/doc/html/model.html)을 사용한 작은 로컬 메시 변형입니다.

## 검증

- 실제 포즈/설정 UI/신규 및 기존 저장 복원: 21개 통과.
- 리아/유진/지현 표정과 저장/불러오기: 41개 통과.
- 서윤 표정 및 기존 저장 복원: 13개 통과.
- 리아 눈 상태/움직임 끄기/저장 복원/통화 숨김: 10개 통과.
- 총 85개 검증 통과. 게임 문법 검사 통과.
- 동일 머리 각도에서 열린 눈과 반감김/감김을 비교: 눈 마스크 밖 변화 0픽셀.
- 기록한 129프레임의 아래 몸통/팔/커피 영역 픽셀은 동일했습니다.
- 설정의 속도 슬라이더 높이를 고정해 아래 움직임 버튼이 가려지던 문제도 수정했습니다.
