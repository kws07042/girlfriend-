# 전체 히로인 피부·머리색 및 포즈 전환 수정 · 2026-10-07

서윤·리아·유진·지현 모두 적용했다. 각자의 현재 MASTER는 기준으로 그대로 표시하고, 추가 포즈 9종에 피부·머리색의 작은 차이를 줄이는 색 보정을 덧붙였다. 리아는 설명·편한 대화·듣기, 나머지 인물은 업무·편한 대화 포즈다.

## 변경

- 기존 두 그림에 각각 반투명 alpha를 주어 겹치던 코드를 제거했다. Ren’Py의 alpha 지원 Dissolve로 이전/다음 이미지의 RGBA를 직접 보간한다. 두 그림의 불투명한 얼굴 영역은 전환 중에도 불투명하게 유지된다. 포즈가 실제로 이동하는 바깥 윤곽에는 정상적인 전환이 남는다.
- 기존 전체 팔레트 보정은 유지하고, 피부·머리 표본을 각자의 MASTER와 비교해 후속 색 보정을 추가했다. 같은 색에는 전신 어디서든 같은 보정을 적용하며, 사각형 피부 패치나 눈·입 합성을 사용하지 않는다. 밝고 어두운 피부·머리 표본을 함께 사용했고 새 단계의 채널별 색 이동은 최대 8/255로 제한했다. 아주 어두운 선은 보호한다.
- 서윤도 이번에는 승인 MASTER에 맞춘 작은 표시 단계 보정을 받는다. 이전 원화 보존 문서의 ‘서윤 표시 보정 꺼짐’ 상태에서 바뀐 부분이다. 원본 MASTER와 포즈 PNG는 수정하지 않았다.
- MASTER·원본 포즈·손·귀걸이·이목구비·이미지 크기는 그대로 보존했다. 눈 깜빡임과 옛 얼굴 합성은 계속 비활성이다. 별도 보관된 새 진지 표정 후보는 이번에도 게임에 연결하지 않았다.
- 움직임 줄이기, 건너뛰기, 전환 완료, 저장 복원 뒤 전환 상태 정리는 기존 동작을 따른다. 새 필수 저장 변수는 추가하지 않았다.

## 검수

- 원본 캐릭터 PNG의 작업 전후 해시가 모두 일치한다.
- 13개 머리 영역의 색 보정 수식 비교에서 투명도와 크기가 같다. 추가 포즈 9개 모두 선택한 피부·머리 표본의 MASTER 대비 ΔE76이 줄었다. 학습에 사용한 표본의 비교이며 모든 픽셀이나 자연스러운 명암을 완전히 같게 만든다는 뜻은 아니다.
- 실제 게임 함수와 SDK의 Dissolve.render를 사용한 함수 검증 92개 통과. MASTER 통과, 추가 포즈의 보정 연결, 전환 중간 RGBA 보간, 캐시 안정성, 전환 완료, 움직임 줄이기, 원화 검수용 보정 우회, 저장 복원 콜백을 확인했다. 표시·렌더 객체는 검수용 대체 객체를 사용했다.
- Ren’Py 문법 검사 통과. 비교 이미지는 RGB 수식 재현이며 실시간 GPU 캡처나 전체 스토리 플레이 검수는 아니다.

현재 실행 중인 게임은 종료하고 **RenPy_게임시작.bat**로 다시 시작해야 새 코드와 보정값이 적용된다. 기존 저장 파일은 이어서 사용할 수 있다.
