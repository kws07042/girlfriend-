# 통화 표시와 종료 수정 — 2026-10-06

- 통화 화면의 원형 종료 버튼과 아래 설명을 단일 빨간색 통화 종료 버튼으로 통합했다.
- 버튼을 누르면 '마무리 중'으로 바뀌고 도현의 종료 요청과 상대의 짧은 인사를 대화창에서 차례로 읽는다. 마무리 중에는 종료 버튼을 숨기며 통화 시간은 계속 흐른다. 두 대사를 넘긴 뒤 종료 상태와 '통화를 마쳤다'를 0.8초 표시하고 기존 스토리 종료 지점으로 이어진다. 종료 상태에서는 타이머도 멈춘다.
- 사용자가 끝낸 통화 기록은 '통화 완료' 대신 '사용자 종료'로 남긴다. 통화를 받은 사실을 나타내는 기존 answered 플래그는 유지한다.
- 실제 장면에서 말한 인물만 ui_scene_actor에 기록한다. 장소가 바뀌면 표시 인물을 초기화하며 집에서는 원격 대사가 있어도 인물 그림을 표시하지 않는다.
- 통화 시작·종료 시 표시 인물을 비운다. 통화와 종료 안내 동안은 상대 프로필만 표시하고 전신 그림은 숨긴다.
- 기존 저장에 새 표시 변수가 없으면 저장된 카메라 인물 상태로 복원한다. 집과 통화 중에는 복원된 인물 그림을 표시하지 않는다.
