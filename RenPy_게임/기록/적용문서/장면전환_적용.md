# 장면 전환 적용 — 2026-10-06

## 실행 동작

- 첫날의 배경 표시 20곳과 2~5일차 공통 week_scene에 ui_scene_show를 연결했다.
- 장소 배경이 달라질 때 표준 with 구문의 0.4초 Dissolve로 장면을 전환한다. HUD와 캐릭터 오버레이는 전환 중에도 표시하며, 장소 이동 중에는 이전 대사를 잠깐 숨기고, 전환 종료 뒤 새 장소의 대사를 표시한다.
- 같은 배경을 다시 표시하는 대사 분기에서는 전환을 반복하지 않는다.
- B에서 C, C에서 B로 바뀔 때 0.3초 동안 크기와 가로 위치를 함께 보간한다. 근접 구도의 어두운 배경도 같은 속도로 변한다.
- 기존 B/C 선택 기준과 MASTER 이미지, 대사 내용은 유지한다.
- 움직임 줄이기 설정에서는 배경과 구도를 즉시 변경한다. 빠른 넘기기 중에는 구도 움직임을 생략한다.
- 내부 저장/불러오기·메뉴 라벨 진입은 구도를 초기화하지 않는다. 실제 스토리 라벨과 장소 변경 시에는 기존 초기화 기준을 따른다.
