# 문자 시간과 답장 정리

적용일: 2026-10-06

## 플레이할 때 달라지는 점

| 상황 | 적용한 동작 |
|---|---|
| 하루 마무리 | 1일차도 21:30으로 표시한다. 21:10 안부 문자가 19:00에 와 있는 문제가 사라졌다. |
| 다음 날까지 안부에 답장하지 않음 | 문자 내용과 답장 선택지를 유지한다. 다음 날 이후에도 답장할 수 있다. |
| 점심 초대·정해진 업무 확인 시간이 지남 | 해당 답장만 만료된다. 원문은 남고 '답장 시간이 지난 약속이에요'라고 표시한다. |
| 한 사람에게 미답장이 여러 개 있음 | 최신 또는 현재 스토리의 필수 답장을 우선 표시한다. '다른 미답장'으로 지난 메시지를 골라 답장할 수 있다. |
| 지난날 메시지에 답장 | '오늘·내일'이 어긋나지 않는 늦은 답장 문구로 바뀐다. 이미 진행한 업무 선택을 변경하지 않는다. |
| 대기 중인 답장이 다음 날 도착 | 받은 날짜와 시간을 실제 도착한 게임 날짜·시간으로 기록한다. |
| 기존 저장을 불러옴 | 일반 문자의 잘못된 만료와 시각·날짜를 정리한다. 답장 완료 이력과 대화 내용은 유지한다. |

대화에는 DAY별 구분을 넣고, 빠른 답장 위에는 어느 날의 메시지에 답장하는지 표시한다. 일반 문자에 늦게 답장했다고 별도 감점을 적용하지 않는다. 기존의 인물별 하루 1회 답장 보상 상한을 유지한다.

## 만료 시각

초대가 도착한 당일, 아래 시각을 넘기거나 다음 날이 되면 미답장 초대만 만료된다. 해당 시각에 답장하는 것은 허용한다.

| 메시지 | 당일 기준 |
|---|---|
| 1일차 리아 점심 초대 | 12:30 |
| 2일차 서윤 체크리스트 | 09:30 |
| 2일차 리아 점심·원자료 약속 | 12:30 |
| 3일차 리아 오전 자료 검토 | 09:30 |
| 4일차 유진 오전 시안 검토 | 09:30 |
| 5일차 지현 오전 목표 확정 | 10:00 |

밤의 안부 메시지에는 만료 시각을 두지 않았다. 읽기 전이나 약속 만료 후에도 메시지 기록을 삭제하지 않는다.

## 확인한 결과

- 날짜 전환과 다음 날 답장: 12개 검증 통과.
- 미답장 전환·만료·보상 중복 방지·기존 저장 복구: 23개 통과.
- 이전 저장의 잘못된 발신·수신 시각: 4개 통과.
- 실시간 전송·타이핑·저장: 18개 통과.
- 대화 스크롤: 10개 통과.
- 알림 표시: 8개 통과.
- 1~5일차 연속 플레이, 전화·선택·약속·주간 결과·저장/불러오기: 24개 통과.

총 99개 검증 항목 통과. 화면의 알림 점이 깜빡이는 미세한 차이를 제외하고 레이아웃도 확인했다.

## 실행과 개발 기준

게임을 재실행하고 기존 저장을 불러오면 복구 정책을 적용한다.

핵심 규칙은 game/phone_message_policy.rpy에 모았다. 앞으로 추가하는 일반 문자는 기본적으로 답장을 유지한다. 정해진 시각의 초대나 업무 선택은 phone_reply_deadlines에 기한을 지정한다. 본문·답장·후속 응답은 작가가 작성한 선택형 대사이며 자유 입력 채팅은 아니다.
