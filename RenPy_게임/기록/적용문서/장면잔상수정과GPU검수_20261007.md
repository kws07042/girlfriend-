# 장면 잔상 수정 및 GPU 검수 · 2026-10-07

사용자가 보고한 첫날 점심 대사 ‘그건 좋네요. 꼭 같이 좋아해야 하는 건 아니니까.’ 다음에 리아의 다른 포즈가 잠깐 나타나는 문제를 수정했다. 관련 장면·포즈·통화·저장 복귀도 함께 확인했다.

## 수정한 내용

| 문제 | 수정 |
|---|---|
| 라운지에서 오피스로 넘어갈 때 이전 화면의 리아가 새 장소의 업무 포즈를 읽음 | 이전 장소 상태에서 정적인 캐릭터 이미지를 확보하고, 퇴장 전환이 끝날 때까지 그 이미지와 출발 구도를 고정 |
| 포즈 전환 객체가 실제 표시 객체 대신 예약 객체(Partial)로 만들어져 빠른 전환에서 예외가 날 수 있음 | Ren’Py의 실제 Dissolve 표시 클래스를 직접 생성. 투명도 보간 수정은 유지 |
| 같은 배경에서 시각·챕터가 바뀌면 이전 인물이 새 내레이션에 남음 | 새 장면 문맥이면 이전 등장 인물과 포즈 전환 상태를 초기화. 다음 실제 대사 때 새 인물이 등장 |
| 저장을 불러오거나 통화를 마친 뒤 숨겨진 인물이 다시 나타남 | 빈 등장 상태를 카메라 인물로 추측해 채우지 않음. 통화 시작·종료 때 남은 포즈 전환도 정리 |

네 히로인 모두 적용했다. 원화·피부색 보정값·귀걸이·손·의상 이미지는 수정하지 않았다. 현재 캐릭터 PNG는 이전 색 보정 작업의 원본 해시와 모두 일치한다. 기존 스토리 대사·분기·보상도 그대로다.

## 실제 엔진 검수

무창 소프트웨어 렌더러에서는 확장 검수 중 충돌이 발생했다. 최종 검수는 SDK의 숨김 창 설정과 정상 NVIDIA GPU 렌더러로 수행했다. 사용자 화면이나 실제 저장 파일을 조작하지 않고 별도 검수 저장 폴더를 사용했다.

| 검수 | 경로 | 통과 항목 |
|---|---:|---:|
| 첫날 점심→오피스, 숨긴 인물의 저장·통화 복귀, 네 인물의 퇴장 포즈·구도 | 3 | 19 |
| DAY 1~5 정상 진행 및 DAY 2~5 약속 조정·휴식 대체 경로 | 2 | 40 |
| 서윤 책·유진 컵·지현 영화 대화의 MASTER/편한 포즈·이후 업무 복귀·저장 복원 | 3 | 23 |
| 합계 | 8 | 82 |

이전 배경 화면이 실제로 렌더되는 동안에도 네 인물의 원본 경로가 계속 편한 대화 포즈를 가리키며, 전환 도중 구도가 움직이지 않음을 검수했다. 저장 후 불러온 빈 장면이 계속 비어 있는지도 확인했다. 완료된 검수 범위에 대한 결과이며 모든 조합의 수동 플레이를 뜻하지 않는다.

기존 사적 장면 테스트의 호감 20 기대값은 앞선 문자 답장 보상 +1을 누락하고 있었다. 게임 보상은 바꾸지 않고, 사적 대화 전후에 호감이 동일한지를 검사하도록 검수값을 바로잡았다.
