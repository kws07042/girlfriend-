# 첫 주 사적 장면과 포즈 연출 · 2026-10-07

첫 주의 업무 사건 사이에 서윤·지현·유진의 짧은 사적 대화를 하나씩 추가했다. 리아 외 인물의 취향과 다음 대화의 실마리를 공통 진행에서도 볼 수 있도록 했다.

| 날짜·시각 | 인물 | 장면 | 남는 이야기 |
|---|---|---|---|
| DAY 2 / 11:55 | 서윤 | 책 사이의 책갈피 | 좋아하는 소설의 결말을 아껴 읽는 습관, 따뜻한 차, 다 읽은 뒤 나눌 이야기 |
| DAY 3 / 18:15 | 지현 | 퇴근 뒤의 영화 | 비 오는 날 다시 보는 오래된 코미디, 직함을 잠시 내려놓고 웃는 모습 |
| DAY 4 / 11:50 | 유진 | 조금 기운 컵 | 직접 만든 삐뚤어진 컵, 결과보다 직접 만들고 쓰는 즐거움 |

장면마다 약 14~15개의 대사·서술 블록을 추가했다. 업무 사건·점심·퇴근 전화의 기존 선택과 시간 순서는 유지했다. 짧은 대화만으로 루트나 교제가 확정되지 않으며, 자동 호감 보너스나 개인 사건 단계 상승을 추가하지 않았다. 다음 주 개인 사건은 그대로 남는다.

## 포즈 배치

승인된 현재 MASTER·업무·편한 대화 이미지를 재사용했다. 표정 이미지나 얼굴 합성, 눈 깜빡임은 추가하지 않았다.

- 첫 인사·대화 시작·업무 정리: MASTER.
- 자료 설명·검토·정리: 업무. 리아는 설명 포즈를 사용한다.
- 책·컵·영화 등 취향 대화, 점심과 퇴근 뒤 휴식: 편한 대화.
- 리아의 기존 듣는 포즈는 첫날 장면에 유지했다.

매 문장마다 바꾸지 않고 주제와 말투가 바뀌는 특정 대사에서만 전환한다. 주인공의 대답 동안 같은 포즈를 유지하며 기존 짧은 전환 효과와 움직임 줄이기 설정을 따른다. 새 사적 장면의 핵심 대사 한 곳씩은 기존 가까운 구도(C)로 보여 준다. 포즈 강제 설정을 계속 남기지 않으므로 다음 업무 장면은 업무 포즈로 돌아간다.

## 변경 파일

story_week01.rpy에 세 장면 호출을 넣었다. story_week01_private.rpy는 대사와 기존 포즈·카메라 규칙에 추가되는 연출 대사를 관리한다. tests/private_week_test.rpy는 첫 주 실제 진행, 세 인물의 포즈 전환, 시각, 후속 업무 포즈, 저장·복원을 검증한다.

현재 24장 기본/진지 후보 세트 중 새 진지 표정을 게임에 연결한 작업은 아니다. 기존 승인 포즈와 귀걸이 수정본을 사용한다. DAY 2 점심 상대의 전체 개방은 이번 변경에 포함되지 않는다.

## 검수 결과

- Ren’Py 문법 검사 종료 코드 0.
- 실제 게임의 포즈·구도 함수에 대한 확인 92개 통과: 연출 대사와 실제 대사의 일치, 이미지 경로, MASTER → 편한 대화 전환, 주인공 답변 중 자세 유지, 저장 복원 콜백의 자세 유지와 전환 상태 정리, 다음 업무 문맥으로의 복귀. 이는 함수·상태 검증이며 실제 저장 파일을 UI에서 불러온 검수와는 구분한다.
- 기존 story_week01.rpy는 세 장면 호출 외 변경이 없음을 확인했다. 승인 이미지·피부색·귀걸이 파일은 수정하지 않았다.
- 실제 게임 UI 연속 진행과 저장·불러오기 검수는 무창 SDL 환경에서 시작 메뉴의 검수 설정 단계에 머물러 완료하지 못했다. 테스트 케이스가 통과했다고 기록하지 않았다. 정상 그래픽 환경에서 tests/private_week_test.rpy 및 기존 office_week 검수를 실행할 수 있다.
