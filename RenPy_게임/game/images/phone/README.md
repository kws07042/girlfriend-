# 친밀도 사진 연결 자리
캐릭터 사진은 요청대로 생성하지 않았다. 자동 전송은 실제 파일이 있어야 작동한다.
각 인물 코드 seoyun/ria/yujin/jihyun + _tier1.png ~ _tier4.png를 넣는다.
1 일상 셀카 / 2 사복 데이트 / 3 옷을 입은 가슴골 셀카 / 4 비노골적인 연인 드레스 사진.
사진 수신 허용 범위는 휴대폰의 수신 탭에서 인물별로 선택한다. 초기값 0.
본편의 관계 사건이 아직 구현되지 않아 첫날 자연 진행에서는 단계 사진을 받지 않는다.
기존 카페 사진은 장소 공유 사진으로 별도 취급하고 첫날 전화 전에 들어온다.
