# 유진·지현 얼굴 크기 통일 v25

2026-10-11. 강리아·한서윤의 현재 얼굴을 같은 확대 배율로 비교한 기준으로 사용해, 유진·지현의 **얼굴 윤곽과 크기**를 맞췄습니다. 유진의 짧아 보이던 볼·턱 길이를 늘리고, 지현의 볼·턱 윤곽과 얼굴 존재감을 함께 조정했습니다. 각자의 얼굴형·눈 색·헤어스타일·인상과 자세는 유지합니다.
