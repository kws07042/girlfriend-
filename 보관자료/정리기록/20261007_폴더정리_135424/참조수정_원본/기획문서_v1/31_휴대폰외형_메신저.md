# 휴대폰 외형과 메신저 디자인

2026-10-01 적용. 참조 시안의 크기와 분위기를 기준으로 네이티브 Ren’Py 화면을 수정했다.

- 둥근 외곽, 금속색 라인, 짙은 청록 레일, 안쪽 검은 베젤과 측면 버튼을 직접 그린 자체 기기 외형.
- 상단 히로인 프로필 48 → 96. 동일한 MASTER 얼굴 영역과 원형 마스크를 유지하며 네 캐릭터 모두 같은 크기.
- 큰 프로필 아래에 동일 너비 연락처 선택, 아래쪽 문자/통화/사진/일정 아이콘 메뉴.
- 배경과 말풍선은 크림/모래색/청록 팔레트. 브랜드 로고와 iMessage 명칭, 외부 공식 아이콘을 사용하지 않는다. 메뉴 아이콘은 코드로 직접 만든 도형이다.
- 메시지 보내기 왼쪽 클립 제거. 입력 영역을 왼쪽부터 넓히고 오른쪽 전송 화살표를 유지.
- 프로필 옆 통화 아이콘은 통화 탭을 연다. 문자 탭의 표시용 입력창/화살표는 자유 입력 기능이 아니다. 답장은 기존 빠른 답장 선택지에서 즉시 전송한다.
- 입력 중 표시, 읽음 상태, 지연 답변, 저장 복원과 중앙 입출장은 기존 방식 유지.

사용자 제공 이미지나 MASTER는 수정하지 않았다. 자체 제작 여부가 모든 국가의 권리 검토를 대체하는 것은 아니며 출시용 사용권 보증 문서가 아니다.

실제 게임 UI 시나리오 실행과 문법 검사 통과. 실행 캡처는 UI_실행_v6에 보관. 변경 전 화면/스타일은 변경백업/휴대폰외형_날짜시간에 백업했다.
