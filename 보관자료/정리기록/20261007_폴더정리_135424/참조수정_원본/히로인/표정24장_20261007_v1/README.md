# 히로인 표정 24장 · 2026-10-07 v1

네 히로인 × 3포즈 × 기본·진지 표정 = 전신 PNG 24장. 각 히로인 폴더에 6장씩 저장했다.

## 구성

| 인물 | 3포즈 | 표정 |
|---|---|---|
| 한서윤 | MASTER / 태블릿+설명 / 태블릿을 두 손으로 | 기본 / 진지 |
| 강리아 | MASTER / 설명 / 커피를 두 손으로 | 기본 / 진지 |
| 차유진 | MASTER / 턱에 손을 댄 생각 / 폴더를 낮게 든 포즈 | 기본 / 진지 |
| 백지현 | MASTER / 팔짱 / 팔을 내린 포즈 | 기본 / 진지 |

기본 12장은 현재 채택한 실행용 원화의 동일 복사본이다. 진지 12장은 각각의 얼굴 확대본을 built-in image_gen으로 개별 편집한 뒤 눈썹·눈·입만 원본 좌표에 반영했다. 얼굴 전체나 전신을 다시 생성하지 않았다. 리아의 기존 listening 포즈도 게임에 그대로 남아 있으며, 24장 세트에는 MASTER·explaining·casual 3종을 선택했다.

## 보존 및 검수

- 전신 PNG 크기: 서윤 2048×3070, 나머지 2048×3072. 이미 업스케일된 원화의 해상도를 유지했다. 이번에는 전신을 새로 GAN 업스케일하지 않았다.
- 각 포즈의 기본/진지 사이에서 눈썹·눈·입 편집 영역 밖의 픽셀 차이는 0이다.
- 투명도 전체 동일. 몸·턱 윤곽·귀·손·소품·옷과 원래의 PNG 색 정보는 보존했다.
- 표정 경계는 부드럽게 연결하고, 작은 국소 피부색 오차는 원본에 맞췄다. 히로인 네 명의 서로 다른 고유 피부색은 유지한다.
- 서윤의 매력점·화장·귀 국소 복원·긴 손 비율은 기존 승인 원화를 기준으로 보존한다.
- 단독 정지 표정 PNG이다. 눈 깜빡임 프레임이나 완성된 Live2D 모델은 아니다.
- 이번 요청은 사진 제작과 스토리 평가이므로 게임 MASTER·실행 스크립트를 교체하지 않았다. runtime_applied=false.

## 제작 기록

생성_프롬프트.json에 built-in image_gen으로 사용한 12개 프롬프트, 대상 포즈, 생성 결과 경로를 저장했다. 입력_얼굴확대는 원본 확대 입력, 생성_얼굴원본은 개별 생성 출력, 생성_얼굴정렬은 좌표 정렬 입력이다. manifest.json은 각 전신 출력과 원화 대응, 편집 영역, 파일 지문을 기록한다. 완료_검수.json과 표정_픽셀검증.json에는 보존 검증 결과가 있다.
