# 강리아 MASTER 업스케일

원본 1024 x 1536 -> 2배 2048 x 3072 PNG.

- 원화 보존형: 원본의 부드러운 그림체를 유지하도록 일반 AI 업스케일 결과와 원본 일반 확대를 40:60 비율로 혼합했다.
- 선명형: 애니 모델의 선명한 선 표현을 적용했다. 원본보다 그림체가 단순해질 수 있다.
- 두 파일 모두 원본 투명도를 2배로 확대한 값을 그대로 사용한다.
- 원본 사본과 일반 모델 4배 작업본, 확대 비교 이미지, 검증 기록을 함께 보관한다.

무료 로컬 Real-ESRGAN 처리. 별도 얼굴 복원이나 Stable Diffusion 재생성을 적용하지 않았다. 원본 MASTER와 게임 실행 이미지는 교체하지 않았다.
