# 히로인 포즈 원화와 업스케일본

2026-10-06 / 총 9종 저장 완료

- 리아: 사용자 채택 포즈 3종.
- 서윤 / 유진 / 지현: 각각 업무 설명과 편한 대화 2종.
- 내장 image_gen 도구로 MASTER를 참조해 새 포즈 제작. 리아는 이미 생성된 채택본 사용.
- 원화와 2배 원화 보존형 투명 PNG를 각 캐릭터 폴더에 저장.
- Real-ESRGAN general 4배 결과를 2배로 축소하고 원화 확대 60% + 보정 40% 혼합.
- 서윤 2048×3070, 나머지 2048×3072. 알파 채널은 원화 크기 정규화 후 2배 확대한 값과 일치.
- 후속 작업에서 포즈/표정의 인게임 연결 및 리아 움직임 샘플 적용까지 완료.
